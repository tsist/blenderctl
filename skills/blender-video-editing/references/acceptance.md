# 验收与能力边界

记录passed/failed/not_run/not_applicable、版本、输入/范围、产物/SHA和可复查报告。只对实测组合给结论，技术正确、agent视听判断和用户审美认可分开。人工检查产出案例；原生编辑→保存快照→inspect/patch→独立重开由agent自动验证。未观察可见GUI列not_run，不能要求用户操作GUI来替代技术验收，也不把后台自动编辑称作GUI观察。

| 层 | 必要观察 | 不足以证明通过 |
| --- | --- | --- |
| 合同/资源 | 完整资源及SHA、规模预算、失败负例 | 注册、Schema、未经检查的空resources |
| 可编辑工程 | 持久保存、独立重开、条带/非目标保护 | 文件存在、FINISHED |
| 时间/画面 | 已知源帧映射、有效边界、切点、速度/停帧、完整解码 | 条带元素查询、短片成功 |
| 声音 | 样本数、同步/漂移、削波、实际听检 | SOUND属性、波形、mixdown返回值 |
| 字幕 | 每句对白覆盖、实际字形/换行、阅读时间、burn-in与SRT | Unicode字符串、packedfont、字幕条数 |
| 创作 | 整体观看/听检、方向与关键审美反馈 | 技术码流、候选自动选用 |
| 有限PQ技术 | 位深、PQ/primaries/CICP、元数据、完整解码、逐帧身份和明示误差门槛 | 标签、SDR截图、普通播放 |

对当前作品先做低分辨率短帧预览，再按必要规模输出。规格改变/重构图重新看主体与字幕。性能报告列镜头数、帧数、尺寸、素材类型、机器/版本、墙钟与实测资源；没测保持未测。存储预算计入图像、整源声音缓存、逐镜ranges、编码尝试和独立QA。预算与超时不是硬内存限额，也不保证系统响应。

## 字幕与音画

字幕完整性先对照文字/SRT/对白清单，检查漏句，再确认所有条带实际烧录。每条首/中/末采样与最后编码都检查，尤其长片后段。字体pack和数量不能证明显示；多字体容量错误须明确拒绝，不静默交付缺字片。复杂背景不能套黑边亮像素阈值。字幕读完与声音清楚仍需实际播放。

可控帧码验证首、中、尾及切点，最终媒体完整解码而非只读metadata。声音比较全PCM样本、cue同步和首末漂移，AAC有限误差另设依据。数值通过不等于音乐比例、对白自然或人的完整听感通过。缺播放/听检能力记录not_run。

## 工程与恢复

源/资源/旧候选保持，目标范围与非目标保护由新进程重开确认。包含锁定、手改冲突、候选替换回退与失败不提交的负例。半开帧域、source_in、速度映射、字幕毫秒和样本时间分开检查。任意外来VSE不在接续范围。

取消以权威job状态为准，核进程/锁释放；恢复到新job保持原请求与身份，独立核candidate及保存前期望、实际重做媒体。不承诺任意partial续算、断电或任意损坏恢复。

## 当前资格范围

已有有限技术与作品证据包括：简单白膜/可控声字幕、真实AI短片、五分钟1080p SDR字幕修订、短4K SDR/1080 HDR代表实片、30分钟受控SDR规模。短SDR案例有用户审美认可，五分钟修订交付获批准；受控循环30分钟只能证明所测帧序/同步规模，不能代替真实30分钟叙事作品。

模板库四样式及自定义、MOVIE、异画幅IMAGE FIT有小型SDR技术证据，适配后的发行包另做低负载验证。用户素材与私有报告不随公开技能分发，这些历史范围摘要不替代当前项目报告。

HLG、外来VSE接续、音频变速/非零声像、高级音频扩展、HDR设备观看已移出支持范围。高负载4K HDR扩展因失去系统响应中断，未通过且不继续；短4K、短HDR与五分钟SDR分别通过不能推出其组合通过。复杂演出、真实长片制作仅为未来目标，不作为当前发行完成条件。

ASR/翻译、生成平台自动提交/取回、专业降噪、多机位/自动波形同步、光流、PR/AE原生无损交换没有支持承诺。新功能需单独研究、最小运行验证和用户确认范围，不以Schema或插件加载证明支持。

具体模式和保留的失败门槛读 [qualification.md](qualification.md)。交付工程与完整依赖、实际媒体、镜头表、候选选用、必要SRT和回退入口；工程能重开与媒体可观看分别确认。
