# 视频与合成的显式媒体交接

剪辑负责镜头时轴，复杂画面效果交给可用合成工具。各自保存可编辑工程，以媒体和交接清单往返；没有任意 VSE/Compositor 节点直连兼容承诺。

- 记录 shot_id、候选/版本、来源工程与源媒体 SHA；序列每张实际帧列入 resources，不只声明目录。
- 分清源帧、剪辑 Scene 帧、序列索引、合成 Scene 帧与回流帧。有理 fps 一致，区间用半开形式，明确有效区间和 head/tail handles。
- 声明尺寸、颜色解释、工作空间、view transform、位深和 Alpha 关联方式。8-bit PNG 不冒充线性 HDR 母版；其它交换路线另行验证。
- 合成保留完整 handles，回流使用显式 source_in 取有效部分，仍携带完整源序列。不能直接将合成第1帧或磁盘编号当原剪辑帧号。
- 输出到新目录，独立重开、实际解码并核对映射/Alpha 后选用。声音保持剪辑时轴，除非交接明确包括声音修改。

既有有限样本为640×360、24/1fps的PNG/RGBA、sRGB STRAIGHT：视频区间[41,53)，有效[43,51)，各2帧handles；合成[101,113)，Exposure(-0.25EV)，完整12帧输出；回流[201,209)，完整序列source_in=2。该样本线性曝光相对baseline及Alpha差0，回流有效非零Alpha区域RGB/Alpha匹配，保存重开、映射与资源身份检查通过。A=0隐藏RGB不承诺信息等值。

源PNG→线性EXR的理想sRGB公式绝对1e-6门槛失败，最大约1.30823e-5；绑定当时OCIO默认CPU处理器的对照误差0。两个参考不相同，运行一致不能抹掉公式门槛失败。资格限此小曝光交接，不延伸任意效果、颜色空间、HDR、声音往返或长序列性能。
