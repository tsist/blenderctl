# 白模近景曲面病害定位与精修

远看轮廓挺正的白模，拉近打一束条形斜光，宽面板上可能浮出放射状碎影，提手根部可能翘起一圈唇边，按钮看似嵌进槽里其实悬空了半毫米。可编辑硬表面的日常布线与卡线直接走 [blender-hard-surface-modeling](https://github.com/tsist/blender-hard-surface-workflow/blob/main/skills/blender-hard-surface-modeling/SKILL.md)；遇到局部返修拿不准病根时按下面四步拆解。

## 四步定位与修复

1. **中灰斜光单件隔离，先给病根归类。** 关掉纹理用纯中灰，固定正交和斜角相机，把问题零件单独拎出来渲一张，分清它是**内部点折叠成碎面**、**两层皮贴太近抢深度产生黑斑**、**高密网格硬加倒角挤出零面积面**，还是**法线插值拉扯**。找准病因再动刀。
2. **宽大弧面嵌板用规则内部网格撑住。** 避免拿中心一个顶点放射连接整圈外框；用顺应外框的四边面网格均匀承托弧度，把极点挪开主高光带，做完先站稳大面再加边缘倒角。
3. **提手与底脚过渡一次只改一个假设。** 提手先用沿路径渐变的圆角截面拉出握持体量，根部检查有没有探出尾壳、露出端盖或留下侧视台阶；一旦改过头出现唇边就退回上一版候选换个接法。
4. **嵌件贴合既看画面也查接触数。** 按钮、指示灯条和凹槽底面核对真实接触与壁厚，做到既严丝合缝咬合、又留出干净的分件缝层次。
