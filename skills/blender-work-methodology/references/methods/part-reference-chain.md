# 多零件硬表面的五级参考与递增组装

做自行车、叉车这类多零件对象时，靠一张总效果图加文字尺寸表直接开干，最容易做成零件悬空、比例失调；等几十个零件全做完再往一起拼，穿插和错位会堆成一团。

## 先锁死五级参考

1. **整机主效果图**：定整体造型、配色和主视角，定稿当场写出一致性核对单（见 [reference-fidelity](reference-fidelity.md)）。
2. **爆炸分解图**：定一共有多少个零件、谁装在谁上面。
3. **单件效果图**：看清每个零件自己的体量和特征切口。
4. **单件尺寸接口图**：标出孔距、轴径、厚度和安装锚点。
5. **整机总尺寸图**：锁死轴距、总高和各部件之间的配合间隙，跟单件接口数字严丝合缝。

五级图全部对齐后存盘锁死；中途发现某处结构讲不通（比如弹簧底下缺承座），回到规格层出修订版，别硬掰旁边的零件凑数。

## 边做边拼，白模过了再上色

1. **白模期用视口纯色区分零件。** 把精力全放在形体、厚度和连接上，一眼就能看出哪个零件做薄了或做糙了。
2. **做完一件装一件。** 每建好一个零件，马上摆进总装工程查穿插、悬空和安装面贴合，问题当场清零。分派给多路制作时，总装工程是最终复验关口，把分件载进来实测求值后的网格和法线。
3. **整机白模跟主效果图对上号，再进 UV 与材质。** 造型关过了，后面调材质和绑定才一路顺畅。
