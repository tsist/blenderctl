## 反例（为什么需要这条，两个）

**反例一（v1，2026-09-25）**：装配案例A 自行车只有"完整效果图 + 侧视比例图 + 文本尺寸表"三级参考，随后用单一大清单一次性生成 68 个对象。结果：挡泥板是零厚度开放飘带、车灯比例/位置错误、曲柄材质错误、链罩缺少参考的标志性长槽。根因：没有部件级参考与部件级验收，生成器按名称想象零件形状；整体材质先行掩盖零件形体错误。

**反例二（v2，2026-09-26）**：装配案例A 重制补上了部件参考图与逐件验收，19 零件全部 0 非流形、尺寸命中 spec、总装干涉清零、绑定正确——但用户判定**不合格**：最终渲染与原效果图天差地别，细节无可取之处。教训：
1. 参考链是边做边补的，从未整体冻结、未做五级冲突排查，各级图漂移累积；
2. 验收口径只有技术指标，"与效果图一致"没有事先定义的清单，看完成品才临时形成标准（先射箭后画靶）；
3. 材质在造型未被用户/主线程对照效果图确认前就完成入库，再次掩盖形体差距；
4. 全部零件做完才总装，装配问题集中爆发。

## 参考链各级的职责（五级，全部完成并冻结后才建模）

1. **完整效果图**：只负责整体外观、配色、主视角；是最终验收的唯一视觉基准。**它生成后立即制定《一致性检验清单》**（造型特征/禁止项/容差），清单先于一切制作存在。
2. **爆炸图**：定义分件清单与装配次序，是规格 JSON 零件表来源。与效果图矛盾先解决再细化。
3. **零件渲染图（每个零件）**：该零件的形状、细节、体量感。
4. **零件尺寸规格细节图（每个零件）**：关键尺寸、接口位置、配合数值，可计算无歧义。
5. **整体尺寸规格图**：全车总尺寸、零件间相对位置与间隙，与所有零件接口数值闭合。

**冻结**：五级齐全后做冲突排查（零件清单三方对应、接口数值与整体图闭合），冻结清单（SHA+对应表+结论）落审计目录。冻结后改动任何一级，必须重查受其影响的全部下级。

## 制作顺序（v3）

1. **白模阶段先解决几何**：零件只赋视口显示色区分部件，先对照参考检验形状与结构。
2. 逐零件对照其渲染图+尺寸图制作与验收，不合格当场返工。
3. **递增组装**：每建成一个零件立即并入装配体，世界空间 BVH 查穿插、间隙与接口锚点查贴合；问题当次清零，不带病累积。
4. 整车完成后**造型对照**：多视角（含效果图主视角）对照效果图，一致性清单中白模可判条目全 pass，才进入材质。
5. **一致性验收**：最终渲染按清单逐条对照原效果图，pass/fail/na 留痕；技术检查（流形/绑定/运动扫掠）是并列口径，不能互相替代。
6. 一致性验收与技术验收双通过才允许入库。

## 与 drawing-spec、reference-fidelity 的关系

drawing-spec（建筑）处理"生成图与尺寸表冲突"；本条处理"多件硬表面的分件、接口、参考冻结与递增组装"。reference-fidelity 负责一致性清单的制定与逐条对照方法，本条的验收阶段调用它。建筑中构件数量多或可预制时可借用本条的部件参考级；载具与机械默认走本条。



## 冻结后的语义复核与装配复验（装配案例A v004 实战修订）

适用于已有冻结参考、接口锚点或子代理分件的继续制作；仍为 candidate，不以本次技术通过代替整车审美认可。

1. **冻结之后发现矛盾时回到规格层。** SHA 一致只证明文件没变。把关键特征写成“所在区域、轮廓、负空间、连接关系”，再对照一级图与实物；出现双槽在前盘、双弹簧没有承座等语义错误，保留冻结原件并另建修订规格，列明取代的旧锚点。不能扭曲相邻零件来迎合错误数字。
2. **安装接触限定对象和区域。** 对装配件先保留全部跨零件三角相交结果，再用具体对象、连接用途及有界接触区分类。同一零件对的其余区域仍受检。BVH 表面相交不能证明没有实体包含；采样最小间隙是连续最小值的上界；离散转动通过也不是全路径保证。按交付用途补充内部、柔性件或连续检测。
3. **参数正确仍须检查构造顺序。** 截面放样核对路径顺序、重复站位、外壁转内壁的绕行方向；发现反射折痕、自交或退化面时，不先加更多线性截面或全局细分。用原始/求值网格、非相邻面自交和无cavity高光小样定位，再局部修正。改变曲面后重新检查承座及支撑净空。
4. **最终装配是分工产物的复验入口。** 子代理完成状态、零件旧QA或“已保存”不构成通过；失败任务遗留文件可回收，但必须读代码、实载分件并在新装配验证。QA绑定当前分件和装配SHA；装配期新增法线/倒角/清理步骤必须记入可重跑的整合脚本，不把分件旧QA冒充最终求值结果。
