# 在可动机械上继续深化细节

机构已经能动了，往上添油缸卡箍、链条护板和驾驶室细节时，最怕新零件堵死原有行程，或者左右镜像过去一边贴紧一边悬空。

## 五步稳妥深化

1. **先圈出必须保住的接口和净空。** 列清新增件装在哪根轴、贴哪个座面、液压缸缩到底留多少余量、给管线和驾驶员留多大空间。支承架顺着真实受力的车架梁往下落。
2. **让相贴的圆孔共用分段数与角相位。** 两个同半径圆环要是分段数不同或转偏了半格，拼在一起就会互相咬穿。在孔环周围排匀环线，发现窄长碎面就重匀间距。测量左右镜像安装面时，两边都读求值后的三角面实测，确认对角线剖分没引起单侧缝隙。
3. **链条和软管先算准路径再铺细节。** 刚性节链先配好整数节数、节距和链轮包绕角，确认销轴进出链轮都贴合再复制链板；柔性软管在起止端和弯曲中段都检查截面有没有瘪掉、跟旁边铁件有没有擦碰。
4. **每添一批件，拉着周围邻居跑一遍行程。** 按 [motion-sweep-check](motion-sweep-check.md) 拨动控制器检查起止、倒车和乱序跳帧，确认新件没撞上老件、老驱动也没被带坏。
5. **收工看整机包围框与操作空间。** 摆进驾驶员或维修扳手参考块核一遍净空，存盘冷重开复验，把辅助参考块留在诊断层里。
