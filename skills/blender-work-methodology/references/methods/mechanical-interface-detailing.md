# 复杂机械的接口驱动细化

本条只解决“已有可运动机构何时可安全增加下一批硬表面细节”。作为候选在匹配任务试用，用下面的失败信号推翻局部方案。参考冻结与递增装配沿用[分件参考链](part-reference-chain.md)，运动检测口径沿用[运动检查](motion-sweep-check.md)，不另建平行验收体系。

## 1. 先定义本轮必须维持的关系

为新增/修改件列实际轴孔、接触区、支承面、轮廓退让、固定/运动端、父级/约束、行程和中立镜像对应。记录物理间隙、数值误差及来源；调整规格时版本化，不能为让报告通过而临时放宽容差。现有未改Action、驱动和几何作为非目标基线。

先测真实求值位置，不能只读父级名、原始rotation或is_valid。双端缸分别核缩回余量、杆轴和孔轴；检查受约束的最终世界矩阵。外壳和支撑要给运动机构、管线和操作者留空间；支承应连到可解释的车架路径，不能沿外观轮廓盲目向下加柱。

若真实机构推翻冻结图或布局，回修对应接口与参考；若只是局部几何问题，保持已验机构并局部重建，避免无证据地重做整条生成链。

## 2. 用接口组织布线，再看外形与可编辑性

- 相贴圆周件共享接口采样/角相位或采取有误差界的适配。半径相同而多边形分段不同仍可能相交。
- 径向孔环和外轮廓先定单一采样，必要转角有限加入并检查最短边、面长宽与拥挤；出现窄面时重分布环线，而非继续叠加采样。圆周段数不固定套用案例值。
- 逐件检查原始四边率、边流、非共面程度与高光曲率；总四边率可能被重复件主导。稀疏控制网格和求值结果分别观察。壳体局部归一化场引出折痕时，试验与目标轮廓一致的连续坐标场；复杂细分壳另读[曲面条目](complex-surface.md)。
- 非共面quad的平均点不是表面真值：接触/包含探针取自求值loop_triangles。镜像顶点不保证Blender选用相同三角对角线；左右安装面都要实测。冲突时优先共同边界支承或合理重构接触面，复验镜像和间隙，不单移一侧或放宽阈值。

## 3. 重复结构和柔性连接先闭合，再加细节

刚性节链先解整数节数、节距、端锚及奇偶装配，分清圆弧近似与多边形链；再生成重复板片。实际求值检查销距/孔心，并检查进入、包绕、退出区的真实接触。无穿透与有预定接触是独立条件。链路运动学成立不证明真实张力/摩擦。

柔管先解运动端点与弯曲余量，若用形态键或路径插值，验端点及中间参数的长度、截面、端切线、曲率和非局部自靠近；不只看中心线端点。按实际变形网格检查相邻机械件，刚体扫掠不替代柔管验收。期望贴合座面或装配缝的探针按参数层取完整关键点集，不能用浮点BVH最近距筛选而漏掉底面。

## 4. 变更范围验收与Rig可重放

本条中的三角面探针和接触范围仅提示细化时的触发条件；测量定义以[运动检查](motion-sweep-check.md)第5–6项为唯一口径。检查新增/修改件对其余相关场景的碰撞、包含和间隙，并保留旧机构回归；旧对象对清单不能覆盖新结构。空间筛选可缩小候选，但必须记录筛选对象、姿态、阈值和未覆盖范围。接触登记到对象与区域，不能整对豁免。

行驶等历史相关输出按实际路径积分后写可重放曲线，保留输入和显式重烘焙入口；不把总行程乘当前转角。检查真实轮心及偏置，保留机构真实转向误差，不为漂亮公式擅改连杆。控制器语义区分位置、速度、状态和限位；起止、停车、反向和乱序跳帧都要检查。

驱动数值异常按“输入类型→表达式→FCurve映射/约束→求值几何”定位。浮点控制保持浮点；identity映射近零异常是版本相关已见反例，只有确认映射严格冗余且限定影响范围才移除，不能全局清除自定义映射。

## 5. 装配完成再核操作空间与质量记录

机械件互不碰撞不代表可操作。驾驶/维护区按目标声明人体或工具代理及其假设，检查可达和净距；由此改位后重验支承、管线和非目标机构。名义代理通过不代表百分位覆盖、完整人体IK或认证。

质量组件用明确且互斥的成员表，分开总成额度与子件；估算质量标来源和区间，质心跟随实际姿态。支承模型适配桥摆自由度，静态投影、前倾矩和动态稳定分开。细节增加后更新归组与敏感性；不把体积×假设密度称为称重或额定能力。

## 继续/返修判断

在本轮声明范围内，造型与技术各自通过、非目标保持后才推进后续细节或材质；相交、悬空、接口漂移、边流拥挤或控制语义不符，回到对应关系修复。连续域尚未证明则保留明确欠账，不把有限采样写成全域通过；按用户当前目标决定下一阶段，不自动将工程认证变为艺术材质制作前置。

最终预览按实际姿态求值包围框构图，保留原始线框/局部/必要剖视，实际看图。保存重开与乱序重放、变更和非目标QA绑定最终文件SHA。诊断代理和展示相机不自动写回资产。
