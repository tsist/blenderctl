# 对照效果图做高还原作品

流形全绿、尺寸达标、绑定能动，渲出来的图如果跟原参考图气质差十万八千里，在用户眼里依然是重做。把还原度抓稳靠下面五步：

1. **开工前先写一致性核对单。** 效果图一定稿，马上把图里的标志性轮廓、特征零件形状（比如链罩上的长条开槽）、比例关系和色块分布逐条列进核对单，写明每条在哪个视角看。做到最后拿这张单子跟原图逐条勾对。
2. **先架一台跟主参考同角度的相机。** 记下透视或正交、俯仰角和主体占画幅的比例，后面每轮白模和材质都在这个机位下跟原图叠看。
3. **白模先抓轮廓和阴影交界。** 重点看屋脊、檐口、倒角转折、踏板厚度这些决定剪影和投影的部位，白模看着像了再进材质。
4. **先对大块明暗色温，再加纹理细节。** 把各物料的明度拉开、冷暖摆准；固定一套评审灯光调准后，再换一套环境光测它稳不稳。
5. **把旧化做出位置逻辑。** 区分整体表面颗粒、单件色差，以及顺着雨水流向、手握边缘和地面溅泥长出来的局部磨损，贴到模型上后按真实尺寸看纹路大小合不合常理。
