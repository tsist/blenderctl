# 概念图冲突时先立规格单

AI 生成的主效果图、正视图和爆炸分解图经常在细节上打架：比如主图是双坡顶，顶视图多画了四坡斜线；或者主图侧面有四扇窗，爆炸图只画了三扇。直接照着某一张开建，做到一半就会卡住。

## 怎么推进

1. **拿主效果图定外观，拿规格单锁数字。** 把楼面标高、阳台面高度、门槛高度、墙皮厚度、屋面上下表皮厚度、平台收边和支脚落点全部写成可验算的数字。遇到影响主视觉的明显矛盾，先重出局部参考图；属于分解图漏画的次要出入，在规格单里写清按哪套为准。
2. **先核连接，再加细节。** 白模搭好后先看屋面盖没盖住墙顶、阳台梁有没有承托、台阶落没落地，确认结构关系全部咬合再往下做板缝。
3. **切完板材查窄片。** 窗洞边缘刚好擦过木板接缝时容易切出极窄的碎条或重合点，进材质阶段前先把零面积面和洞口遮挡清理干净。
