# 复杂曲面：控制网格、厚度与后续UV

**适用信号**：厚皮壳、软硬复合外罩等细分曲面，流形与自交检查通过但仍有反射波纹、局部瘪陷，或用户要求后续UV/贴图可用。装配案例A用户认可v004整体，却明确指出车座粗糙和踏板过薄；此前技术通过不再支持车座已完成的结论。本方法仍为candidate，不把一张四边面皮壳推广为所有建模对象的默认拓扑。

- **先改变形状表达，再决定面数。** 当波纹来自密集且不连续的截面控制，先用少量有连续切向/曲率的形状锚点定义鼻部、承托区、肩部和侧裙，再安排跟随这些区域的边环。以低级控制网格可读性、轮廓、无cavity高光和原始/求值自交联合判断；更多面、全四边面或细分成功均不能独立证明流畅。硬折角、局部结构细节不应被一律平滑掉。
- **后续UV要求前移为建模验收。** 对需要独立内外皮的有厚度壳体，显式区分外皮、内侧和切边；接缝放在不显眼的下沿，长切边按打包和拉伸需要分段。用户要求检查UV时可用隔离的临时棋盘格诊断；它不代表正式材质阶段开始，不将诊断材质写入白模交付。先检查控制网格，再检查最终细分级别：翻转、退化、越界、岛间重叠和有界拉伸数据都要与实际棋盘格一起看。
- **细分UV设置也会改变结果。** 窄切边端点可能被UV全平滑过度收缩；不能只验原网格的UV。装配案例A保留角点后细分UV最大各向异性约1.83、切边约1.34。数值仅描述本例；保留角点不是通用最优。记录邻接边的浮点量级交叠与非邻接岛重叠的区别、阈值和纹理分辨率，不通过放宽阈值制造“数学零重叠”。
- **视觉厚度定位到截面。** 面板/踏板看起来薄时，测主体、边沿、倒角退让和附加防滑件，避免只看整体包围盒。加厚平台应保护轴心与轴承截面，并检查代表转动姿态；加厚后不沿用旧运动证据。

证据：v005制作与验收（历史工程证据未随包发布）、同机位/控制网格/UV实渲染（历史工程证据未随包发布）、UV原始数值（历史工程证据未随包发布）。仅支持本车座、踏板和Blender 5.2.1；未覆盖布料变形、制造展开、其他形状或完整整车贴图流程；用户已允许以v005进入材质阶段；这不构成跨物体泛化验证。

## 可迁移的判断顺序

1. 先把曲面分成承托面/过渡肩部/侧裙/端部/切边等实际区域，确定需要连续光顺与需要保留硬转折的位置。结构、轮廓和安装锚点先于微细节。
2. 用控制曲线表达轮廓与主要曲率，再安排顺着曲面变化的边流和必要支撑环。曲率突变先查控制点和构造方向，不先堆面。极点尽量避开主要高光与高变形区；全四边面不是独立的质量指标。
3. 检查局部厚度与端部收束。显式内外壳适合需要分开的内外纹理；Solidify等可编辑方案也可选，但必须检查求值厚度与UV关系。设计曲线C2不等于整张细分极限曲面处处C2。
4. 在交付细分级别下看UV和棋盘格，并单独记录原网格与求值结果。接缝位置服从可见性、材料方向与后续编辑，不把“更少UV岛”视作固定目标。
5. 对曲面改动重新检查相邻支撑和运动件。保存后独立重开，确认控制网格、修改器、UV及非目标内容确实保留。

这些是本例支持的候选决策。1,134面、3.5mm厚、2级细分、6岛、Preserve Corners均为实例参数，不写成所有物体的默认值。用户允许继续材质只说明本案例制作可以前进；新的物体仍须按其目标检验。
