# 运动机构的行程干涉与接触检查

静态看着严丝合缝的机械，曲柄一转满圈，踏板可能就撞上链罩；新加一颗轴头螺丝，也可能在举升到最高点时刮到护板。

## 怎么查得稳

1. **列清行程与耦合组合。** 能整圈转的测满 360°，有限位的按真实行程测；除了单轴运动，还要测两个关节同时动（比如边转向边起伏）的组合姿态。新改了哪个零件，把它跟周围所有邻居都拉进检查范围。
2. **拨动真正的绑定控制器来测。** 通过控制器改姿态、刷新依赖图，读求值后的三角面网格和世界矩阵，这样约束限位和连杆联动才是真实生效的。
3. **在擦边位置加密采样。** 按零件尺寸和最小间隙选基础步长，到了快擦上的临界角、行程两端和拐点附近把采样加密。汇报时说清测的是离散采样点还是连续包络。
4. **相交、包裹和设计接触分开算。** 先做包围盒粗筛，再测真实三角面相交；对闭合壳体补测内外包含（防止一个小零件整颗陷进大壳体肚子里却零表面相交）。原本就该贴在一起的轴承座、销孔，按具体对象的局部接触区登记核销，同一零件的其他部位照常查碰撞。
5. **存盘冷重开，再看一眼画面。** 保存后另起进程重开工程，抽检起始、中间和临界姿态，并渲出完整姿态图亲眼确认没有遮挡穿帮。
