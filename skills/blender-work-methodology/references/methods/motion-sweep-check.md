# 运动件干涉与接触检查

装配案例A静置通过后，曲柄公转暴露踏板与链罩碰撞；后续角度检查又暴露货架、后叉等局部问题。机械案例B继续证明：已通过的旧指定对不能覆盖新加轴头，轮板不穿透也可能悬空。本条仍为candidate，不因两个案例自动晋升。

## 检查顺序

1. **定义范围**：区分机械可达域、有效作业域、演示路径；列本轮新增/修改件及其余场景的候选关系，保留旧回归。单轴覆盖之外检查会改变相对姿态的耦合组合。
2. **驱动实际Rig**：用控制器达到姿态、更新依赖图，从求值网格和世界矩阵测量。限位后的结果不等于原始属性；不得手摆对象代替联动检查。
3. **确定采样和连续声明**：只有能完整旋转的副才测360°，有限转动/平移按真实限位。步长依据几何尺度、最小间隙与运动速度初选，在擦边、分支、端点及短行程的中间经过状态加密（不能只测首末）；固定1°或逐帧不构成连续保证。连续声明需保守扫掠、可靠连续碰撞或结合误差界与运动界覆盖区间，否则明确not_run/未证。
4. **分层量测**：先空间筛选，再测真实三角表面相交；闭合实体补包含检查。BVH零相交不排除完全包含。最近面法线符号有旋转/空心体误判风险，用适合网格条件的包含算法和已知内外点fixture交叉核查；开放/自交几何需代理或声明未证。
5. **距离与接触分开**：双向顶点到表面最近距是最小间隙的采样上界，可能漏边—边最接近并高估净空，不能作为保守安全下界。需要净空保证时采用覆盖边/面的距离方法或有误差界的下界。预期接触单独取真实表面探针；非共面quad使用求值loop_triangles。
6. **有界接触裁决**：每项记录对象、局部区域、用途、允许接触形式及规格阈值；只接受该区域内有依据的装配接触。不得用整对design_contact屏蔽区域外穿透；相交数量本身不作最终裁决。
7. **复现**：保存后独立重开同一最终文件，复验关键/中间/临界与乱序状态，绑定SHA及方法版本。记录pass/fail/not_run/not_applicable，保留失败和修复影响范围。

柔管需另外验变形中间态、长度/截面/端切线/弯曲及非局部自靠近，参见[机械接口细化](mechanical-interface-detailing.md)。链条解析闭合不代替实际网格接触检查。最终图像核对完整姿态和遮挡，避免只看数值。
