# 渲染与风格化部门

负责把调好的场景、镜头或三渲二风格稳定地算成单帧画面、分层通道与多镜序列审片。

## 从上游收什么

- 镜头与灯光（或动画与模拟）交来的定稿工作副本（路径与 SHA）、镜头表、已烘焙的物理缓存回执与外部贴图清单。

## 选路与专项技能

- **三渲二风格与二维描边**：读 [blender-toon-workflow](https://github.com/tsist/blender-toon-workflow/blob/main/skills/blender-toon-workflow/SKILL.md)。按参考把角色或指定部件切到 Toon 着色（含面部 SDF 影形、法向修正、色阶与高光），其余背景或道具可继续保留 PBR。视口手调描边和影形后先保存工作副本，抽代表帧对照后台线稿输出，再跑一段含转头或遮挡的连续帧检查线条稳不稳。查 CLI 动作运行 `discover --product toon`。
- **静帧与多镜头批渲染**：静帧或单段测试可直接走 `blenderctl` 的 `render`，多镜头动画读 [blender-render-batch](https://github.com/tsist/blender-render-batch/blob/main/skills/blender-render-batch/SKILL.md)。开跑前先按风险试渲：静态镜抽一两张代表帧，有运镜、模拟或描边的镜跑一小段连续帧。确认曝光、采样、引擎设备和通道无误后，按镜头表提交批次并生成 H.264 审片。个别镜头失败时独立镜头照常跑完，修好后只补算受影响的帧。查动作运行 `discover --product render-batch`。

## 交给下游什么

- 渲染好的图像序列或静帧（标明色彩空间、Alpha 方式、分层通道名与帧段）。
- 带镜头编号的审片视频与批次状态记录，供合成接线或剪辑原位换片。

## 什么时候给用户看

- **无后期合成的静帧或镜头**：直接作为镜头的**审看②（最终帧）**交给用户。
- **要进合成或剪辑的序列**：先抽查代表帧无噪点、无丢贴图、无穿线后交合成或剪辑部门，合成完再给用户看。

## 出了问题回哪里修

- 噪点重、采样不够、分层通道漏勾或引擎选错：留在本部门调渲染设置补算。
- 三渲二轮廓线抖动、穿进五官或脸部阴影乱跳：留在 Toon 环节修描边集、SDF 控制点或退回建模修法向。
- 物理缓存没加载出来或某几帧布料炸裂：退回动画与模拟部门重检缓存闭包。
- 真实遮挡错位、阴影投不到地面：退回镜头与灯光或建模部门修场景。
