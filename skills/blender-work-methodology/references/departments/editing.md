# 剪辑部门

负责用 Blender VSE 把分镜预演、正式渲染画面、对白音乐与字幕编排成节奏顺畅的成片。

## 从上游收什么

- 镜头与灯光部门的镜头表主档和各镜分镜预演媒体（粗剪阶段）。
- 渲染或合成部门按镜头编号输出的正式媒体序列或视频（精剪阶段），以及音频、旁白和字幕素材。

## 选路与专项技能

- **建时间线、粗剪与原位换片**：读 [blender-video-editing](../../../blender-video-editing/SKILL.md)，用 `discover --product video` 查入口。先按镜头表摆好各镜预演、音乐节拍和临时字幕，做成能从头放到尾的粗剪。等下游正式渲染和合成陆陆续续出片时，按稳定的镜头编号原位替换对应条带，保住已经调准的入出点、转场、音轨和字幕。
- **接手现场时间线**：用户在打开的 Blender 窗口里手调了剪辑条带时，先用 `video inspect-live` 读取当前时间线状态，另存为工作副本后再交给后台处理。
- **改切点先对齐镜头表**：剪辑时发现某个镜头要延长半秒或提前切走，先把新切点写回镜头表主档（VSE 采用左闭右开 `[start, end_exclusive)`，换算回镜头表和批渲染的闭区间 `[first, last]` 按 `last = start + duration - 1` 计算，防差 1 帧），再通知相机、动画和批渲染补足对应帧段，保持全片一盘棋。

## 交给下游什么

- 保存好的可编辑 VSE 工程副本（路径与 SHA）与可重连的外部媒体清单。
- 导出的可播放成片视频（核对过分辨率、帧率、音画同步与响度）。
- 需要跟外部剪辑软件交接时，附带纯剪切 OTIO 时间线文件。

## 什么时候给用户看

- **审看①（粗剪）**：全片用分镜预演或灰模拼通、配上声音节奏后请用户看，在投入昂贵的正式渲染前把镜头顺序和时长敲定。
- **审看②（精剪）**：全部正式镜头换齐、字幕与混音到位后请用户终审，通过后导出正式交付成片。

## 出了问题回哪里修

- 镜头衔接跳轴、转场生硬、字幕错字或音画不同步：留在本部门调整条带和音频偏移。
- 某个正式镜头帧数不够、入出点跟镜头表对不上：先核对镜头表，再退回渲染或动画部门补齐帧段。
- 两镜之间色调跳脱太明显：退回合成部门统一前后镜色温与黑位。
