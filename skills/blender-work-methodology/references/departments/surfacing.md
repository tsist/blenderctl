# UV 与材质部门

负责在定稿白模上展开合理的 UV，做出经得起近景和换光检验的材质与可移植贴图。白模确认后再开工，避免形体返工连累 UV 重展。

## 从上游收什么

- 建模部门交来的定稿白模工作副本（路径与 SHA）、部件对象名清单，以及需要高低模烘焙时的配对高模。
- 前期参考里的物料说明、表面质感参考与标识朝向要求。

## 选路与专项技能

1. **先展 UV**：读 [blender-uv](https://github.com/tsist/blender-uv-workflow/blob/main/skills/blender-uv/SKILL.md)。按表面用途分配图幅：要有独立磨损、文字标识或烘焙贴图的面给独占 UV；外观完全一致的重复小件共用一套 UV；近景主面留够像素密度并摆正纹理方向。查 CLI 动作运行 `discover --product uv`。
2. **再做材质与贴图**：读 [blender-material-authoring](../../../blender-material-authoring/SKILL.md)。在统一的中性灯光下调材质，把材质本身的表现和镜头打光分开。需要空间图案或复杂遮罩时优先用代理原生生图准备素材，再由插件和 CLI 组装节点、投射高低模法线/AO/曲率并导出贴图。查动作运行 `discover --product material`。
3. **接手现场手调**：用户在打开的 Blender 窗口里调好了材质层时，用 `material handoff-live` 先检查再提交成可恢复的工作副本。

## 交给下游什么

- 保留完整可编辑着色节点与 UV 层的主工程副本（路径与 SHA）。
- 导出的颜色、粗糙度、金属度、法线等贴图文件，外加一份只用导出贴图在干净工程里重建的验证副本。
- 材质槽清单、UV 层名与色彩空间说明。

## 什么时候给用户看

- **可复用资产**：这是**审看②（最终材质）**。达到 L2/L3 标准的资产，先由未参与制作的独立只读子代理跑 [blender-modeling-review](https://github.com/tsist/blender-modeling-review/blob/main/SKILL.md) 盲审过线并产出 `quality-scorecard.json`，再把可编辑节点版、干净工程纯贴图重建版与 EEVEE Next 光追对照（含整体、关键近景和棋盘格）呈给用户审看。
- **角色或镜头资产**：自检通过后交绑定或镜头与灯光部门，随动作预览或最终帧一起看。

## 出了问题回哪里修

- 贴图拉伸、接缝露在正面或文字反了：回到 UV 环节调整接缝和岛方向。
- 高光扭曲、倒角太死或高低模投射穿笼：退回建模部门修网格、法线或笼体厚度。
