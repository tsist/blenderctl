# 方法索引与实践入口

## 最高工作指导

先执行[插件与CLI工作单元](plugin-cli-work-units.md)的适用性判断，优先把连续多步交给插件封装、CLI调度。该条是用户指定的工作优先级，不计入下表领域方法成熟度。

## 次级工作指导

最高指导之后执行[完整工作单元与效率](efficient-work-units.md)：准备足够输入与有限候选，读取诊断、差异、进展与恢复引用，以真实瓶颈决定下一轮。它低于插件/CLI协作指导，不计入领域方法成熟度，也不因少调用晋升validated。

## 当前成熟度

当前六项candidate、零validated领域方法。旧材质条目及专门章节已经移除；登记仅包含下列保留的方法，版本以SKILL.md为准。建筑案例A早期外观和装配案例A两轮参考偏离的用户反例仍说明：技术通过不能替代作品质量。

## 材质制作阶段跳转

材料参考、分层、着色节点、贴图及材质验收转 [Blender材质制作技能](../../blender-material-authoring/SKILL.md)。PBR属于其 `references/pbr/framework.md` 章节，不单独设技能。该入口0.2.0已建立原生生图优先硬规则与完整规范：各图层/复杂遮罩首先原生生图，实际受阻才回退Kie等，简单渐变/数学依赖遮罩可用Blender。插件与CLI执行层遵守其内容来源约束。赤陶v008基本验收案例属于材质技能，不计入下方六项candidate领域方法，也不恢复旧退役配方。

## 实践时可选择的观察方向

| 任务方向 | 值得观察的工作决策 |
|---|---|
| 建模、雕刻与结构修改 | 何时锁定大形和增加细节，怎样验证局部修改未破坏整体？ |
| 灯光与画面制作 | 怎样隔离相机、照明与色彩条件的影响，用什么实际画面判断质量？ |
| 骨骼与动画 | 哪些姿态和时刻最早暴露问题，怎样减少反复返工？ |
| 模拟、毛发与程序化制作 | 用多大范围的小样检验关键动态，何时投入长时间求值？ |
| 修改既有工程与格式交付 | 怎样控制影响面，并在目标环境确认交付质量？ |

这些是可选的学习问题，不是固定任务单或已验证结论。任务覆盖面与结论可靠性分别记录，不以做过某方向替代方法验证。

## 建筑几何实践

[基础建筑硬表面建模](architecture-basics.md)归纳建筑案例A/建筑案例B/C的规格、洞口、搭接与构件身份。建筑案例B/C零宽截面、建筑案例C墙皮穿屋面是反例；三栋作品数量不构成方法晋升条件。建筑案例B/C实证（历史工程证据未随包发布）只在本入口引用几何证据，用户审美反馈另记。

## 分件、曲面与装配实践

装配案例A v004补充冻结后语义复核、对象与区域级安装接触、放样构造顺序及最终装配QA绑定。用户接受整体却指出车座粗糙、踏板薄，促使v005补充控制网格、曲率、厚度、实际细分UV与棋盘格检查。数值与特定细分设置仅描述本例，候选状态保持。各原始证据见登记表，不将历史技术通过扩成新的用户质量认可。

## 机械接口与运动实践

机械案例B硬表面与Rig复盘保留机械接口细化、离散与连续覆盖、实体包含、区域接触豁免及变更回归的判断。单叉车多次迭代不构成跨资产迁移，未提供工程承载认证。
