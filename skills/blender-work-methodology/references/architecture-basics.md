# 建筑硬表面外观：从概念图到可编辑模型

做概念图驱动的静态建筑外观时查这里。目标是把好看的效果图落成尺寸闭合、构件分明、可复用的三维网格。

## 先把空间关系算闭合再建模

1. **效果图管气质，规格单管尺寸。** 拿到正视图、透视图或爆炸图后，先把建筑总宽深、层高、檐口与屋脊标高、屋脊走向、门窗数量和阳台出挑写进规格单。不同视图画得不一致的地方（比如爆炸图多画了一层墙壳或少画一扇侧窗），挑一个既符合主视角外观、空间上又讲得通的方案写明，再动手建白模。
2. **大形看三个角度。** 白模阶段同时看主视角、侧后视角和入口近景；屋檐比例或墙高跟参考差得远时直接改大形，留在白模阶段解决。

## 外壳做出真实的构造搭接

1. **门窗真开洞。** 在墙体网格上实打实留出洞口，配齐窗框、玻璃和洞口进深，斜侧光下看得出真实的阴影层次。
2. **逐处查搭接。** 沿着墙皮与屋面、檐口、勒脚、台阶、平台和雨水管交界走一圈：修掉穿出屋面的墙皮白线，补齐悬空的平台支脚和管口。
3. **清理切洞留下的碎面。** 用修改器或布尔切山墙斜面和木板墙洞口后，跑一遍检查，清掉接近零宽的窄条、重合顶点和零面积退化面，保证每个窗口干净畅通、UV 好展。
4. **保住整根构件的身份。** 一根长木板被窗洞截成左右两段时，在命名或属性上仍按对应板材管理，拓扑改完重新核对一遍材质与属性归属。

## 交付前独立验收

另起进程重开资产 `.blend`，把主集合追加到干净空场景里存盘重开并渲一张图，确认网格、UV、打包贴图齐全且脱离原工程也能独立使用。
