# 面部表情、姿态修形与控制板

身体与主服装基础蒙皮验收后，再做面部表情、控制板整理和深屈曲姿态修形。这一阶段的核心是保住静置基线一致、表情通道可复用、多网格联动干净以及控制板顺手好找。

## 面部表情制作顺序

先稳住头部与颈部基础权重，再做骨骼表情与形态键采样，最后统一映射到皮肤与附件：

1. **先做骨控混合，再整组采样形态键**：头部基础蒙皮核验通过后，用面部骨骼调出闭眼、微笑、皱眉、张口、口型等标准表情，再把同组骨骼姿态整批采样成角色形态键（Shape Key）。按整组混合采样，确保眨眼叠加张口或情绪叠加口型时过渡顺滑。
2. **已有形态键局部返修**：对已有语义通道需要微调造型时，通过固定版面部键返修流程（`face-key-revision`）创建独立草稿、`face_key_revision_preview` 按成员索引预览，手改满意后先执行 `stop_preview` 清零预览值再提交，生成独立的候选控制器与网格，原 Basis 与其余形态键原样保留。
3. **跨网格同步同一表情**：角色的脸部皮肤、眉毛、睫毛饰件或面罩常常分属不同网格。通过 `key_mapping_sources` 与 `key_mapping_channel` 建立映射行，在 `key-mapping` 设置中逐行指定语义和各网格实际键名，再执行 `key_mapping_create` 生成联动副本。独立冷开验证同一滑杆驱动全部成员同步变形并准确回中立。
4. **口型板与日常表情录制**：通过 `expression-controls` 指定角色与表情控制器，编辑普通表情板滑杆分区或配置口型板（8 个口型格与 15 个滑杆）。日常录制口型和表情时调用 `face_daily_axes`、`face_daily_slider` 与 `face_daily_record`，在当前帧写入表情关键帧的同时保护原有身体动作。

## 控制板与侧栏布局整理

交付动画部门前，把动画师高频使用的躯干、四肢和表情控件排到顺手的位置，并改好直观的中文或业务标签：

- **身体控制板编辑**：先用 `rc-control` 的 `inspect` 读取当前布局行 `data.controls.layout.rows` 和布局指纹 `data.controls.layout_sha256`。在同一角色、帧和视图层提交 `operation=control-layout`，填入刚读回的 `expected_layout_sha256`，按稳定的 `row_id` 执行重命名（`LABEL`）、上下移动（`UP` / `DOWN`）、切换显隐（`TOGGLE`）或切换编辑态（`EDIT_MODE`）。每次写入指定新的 `--output`，后续修改顺着新候选的文件 SHA 与最新布局指纹继续。
- **表情侧栏布局编辑**：通过 `rc-face` 的 `author-sidebar-layout` 选定角色的 `hub`，按 `channel` 调整表情标签、分区、排序、显隐和列数（`COLUMNS`）。每次修改保留当前 Action 和独立保存候选。
- **原骨架维护包控件与写键**：维护外部已有骨架时，在 `--background-maintenance` 会话中先用 `READ` 读出完整布局和网格成员，再经 `ADD_CONTROL` / `ADD_PROPERTY` / `ADD_KEY` 迭代草稿，带上最新布局 SHA 执行 `APPLY_LAYOUT` 生效。给可见控骨写关键帧走 `KEY_CONTROLS`，系统会产出新的 Action 与 Slot 并把原 Action 保留为检查点。

## 逐姿态修形（Pose Corrective Shape Keys）

当主骨骼和权重在多姿态下已经合理，但肘、膝、肩、胯在深屈曲时仍缺少自然压褶或体积补偿，可以制作逐姿态修形形态键：

### 1. 先打磨单侧单态目标曲面

- **在三维原网格上划域**：先在原网格定位真实的凹陷或折痕，按三维曲面、RAW 边和原面圈定作者域与保护外环。
- **先过一个决定性姿态再扩锚点**：先在一侧的峰值或关键过渡态做出肉眼明显改善的目标曲面；确认有明确收益后，再制作半程、90° 等中间锚点并推广到对侧。
- **区分 posed Smooth 与 Corrective Smooth**：在摆好姿态的网格上做单次原生 Smooth 可以定向整理局部凹窝，再用逆解写回形态键；Corrective Smooth 修改器则适合做可开关的表面平滑对照。

### 2. 保住真实消费层与精确逆解

- **计入全部非零权重与 B-Bone 段**：计算姿态到静置空间的逆矩阵时，按顶点全部非零骨权构造逐点 LBS 矩阵；遇到脊柱、尾骨或四肢多段 B-Bone，即使贡献很小，也复用原生 `bbone_segment_index` 与相邻段矩阵混合。先混合全部骨变换矩阵，再在物体/骨架空间整体求逆（连同物体缩放一起算），避免位移量级偏差。
- **逐态核对重放精度**：校验原生 CrazySpace 见证、奇异值稳定度和域外零位移，提交后再对实际 RAW 与细分表面重放验证，确认关闭修形键后精确回到原皮肤。

### 3. 编写稳定的关节驱动与多锚点曲线

- **读取实际求值的相对关节旋转**：驱动变量绑定到真实变形骨（例如 `DEF-shin`）在 `LOCAL_SPACE` 下的 `SWING_TWIST_Y` 相对旋转分量，避开直接读 FK 控制器或视觉估算角度。
- **清空 `driver_add` 默认点再写显式节点**：Blender 调用 `driver_add` 时会自动生成两个默认曲线点。编写多锚点驱动曲线前，先调用 `fcurve.keyframe_points.clear()`，再按锚点数量 `add()` 并逐点写入坐标、手柄类型（如水平三分之一 Bezier 手柄）与常量外插（`CONSTANT`）。写完并保存后另起进程冷开，逐点读回节点坐标、手柄类型与曲线求值。
- **多锚点区间权重分配**：从静置中立到第一锚点之间，显式形态键之和小于 1（余量由 Basis 承接）；相邻两个显式锚点之间保持权重之和为 1，并夹住中立附近微小残差与域外角度。
- **全范围复验**：依次验证所有锚点、相邻锚点中点、锚点前后半帧、对侧与组合姿态；确认各态开关修形后原皮肤与新表面都可复现，且域外顶点完全不受影响。

### 4. 单姿态局部补形与 Corrective Smooth 对照

- **单姿态手调补形**：需要针对某一个特定动作帧做局部造型微调时，使用 `rc-control`（或固定版对应入口）的 `corrective-begin` → `corrective-edit-target` → `corrective-commit` 流程，明确作用区域、对象和位移上限，生成可随时开关的手动 Shape Key。交接时注明作用帧号，跨姿态检查前记得归零。
- **Corrective Smooth 表面对照**：在已有绑定出现屈膝折痕时，用 `rc-modular` 的 `operation=surface-candidate`（配 `pin_boundary` 固定边界点）生成带原生 Corrective Smooth 的独立候选，让下游在同机位切换修改器开关，对照中立、中间和峰值姿态以及折痕两侧邻面，有净收益才采用。

## 新建 PoseBone 自定义属性驱动的初始化提示

当新建 PoseBone 自定义属性驱动在首次求值出现无效提示时，先核对原始与求值目标路径以及生产流程里的初始化更新步骤，按完整更新链触发依赖图刷新后再读回求值状态，保持原工程安全设置与真实驱动校验逻辑不变。
