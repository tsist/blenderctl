# 体素蒙皮、局部修权与变形诊断

骨架通过双审与用户审看①后，进入这一份指南。按「整角色体素求解与转权 → 规范看图诊断 → 分层定位原因 → 有保护选骨局修 → 独立冷开复验」的节奏推进，每一轮改动都用同机位前后图说话。

## 整角色体素蒙皮与同作业转权

新角色默认使用体素蒙皮公共入口（用 `discover --product rigging` 确认当前推荐候选发行版），核心子命令位于 `rigging-workflow candidate-entry`：

1. **核对生产网格与计算代理**：生产 RAW 负责保住原始点序、拓扑与 UV；网格存在开口或薄壁时，在独立计算副本生成闭体代理，留作体素占据与体积扩散场计算，原始生产网格保持完好。
2. **单域或多域规划（`inspect` / `scope`）**：检查源工程 SHA、场景、视图层、骨架和部件清单；头部、躯干、四肢需要不同采样精细度时拆成多域，写清每域代理、骨列、遮罩与刚性范围。
3. **同作业部件转权（`bind_transfer`）**：贴体袜子、手套、内衣等需要直接继承身体权重的部件，在 `scope` 请求的 `transfer` 块中写明 `part_index`、`donor_part_index`、`max_distance_meters` 和 `name`。写前自动校验部件冲突、超距与签认，求解阶段直接从同作业刚应用好的真实身体供体做近面转权。
4. **试片求解与缓存复用（`audition`）**：在独立 `--run-dir` 执行 CUDA 体积求解、身体绑定、刚性件绑定与部件转权。重开后继续同一角色时，在请求中填写上次原生作业根路径 `worker_jobs_dir`，输入与权重指纹一致的域自动复用，只重算发生变化的域。
5. **受支持表面回传与内点混合采样**：体积场回写到生产网格时，只用三个顶点均受体素支持的完整代理三角做有界重心插值，覆盖距按体素格宽和场景单位明确上限。遇到代理重网格丢失极少数内腔点时，先验证超距点严格落在闭体内部且具备可见体素支持，再用显式互斥的内点混合采样回填，保持全部原行序与完整骨列非负归一。
6. **独立冷开与交付收口（`result` / `finish`）**：审片通过后用 `result` 在新进程核验部件数、权重列、代表动作态与源 SHA；最终用 `finish` 产出交付副本，开启 `isolate_bound` 让打开工程时默认选中骨架并展示已绑部件。有睫毛、嘴唇等需人工接续的部位时，把 `manual_handoff` 工单连同复验动作帧写进完成请求。

## 规范看图与联合检查

观察皮肤质量前，先统一视口显示和对照基准，让每一处褶沟、鼓包和接缝都真实可见：

- **统一表面与线框设置**：保持目标几何表面完全不透明、关闭表面透显（X-Ray），从完整求值网格（`Mesh.edges`）叠加全部线框；普通边设为统一中性色、只给重点排查局部标色，取消整网选中橙色，线框透明度从 0.6–0.7 起步按可读性微调。同时开启原生屏幕空间曲率（`show_cavity=True`、`cavity_type='SCREEN'`），并配同机位无叠线实面图对照。
- **同姿态联读四类信息**：在同一动作的中立、中间、峰值和反侧视图里，同时对照原生实面与线框、相关多骨组的 RAW 权重与总和、CTRL→ORG/MCH→DEF 实际骨链及 B-Bone 段、以及修改器输入。权重色标写明 0–1 范围与显示模式。
- **区分动作帧与子帧**：记录动作索引时同时保留整数 `frame`、`subframe` 与 `frame_float`，重放时调用 `frame_set(floor(t), subframe=t-floor(t))`，避免漏掉匹配半帧。
- **全身与近景配套**：先看全身轮廓与反侧，再补活动侧前后斜近景，确认局部修权没有把体积挤压转移到邻域。刚性件核对变换、形状、连接和切换瞬间。

## 变形异常分层诊断表

出现拉扯、凹陷、开缝或异常折痕时，先判断问题出在哪一层，再做能区分原因的最小改动：

| 观察到的现象 | 优先排查层级 | 下一步最小动作 |
|---|---|---|
| 静置或未动时已有错误轮廓、尖褶或层间无通过空间 | 原模形体、服装设计余量 | 标出几何瓶颈，退回建模部门补环线或留活动量 |
| 无皮肤时关节轨迹、肩带联动或铰链轴已偏离用途 | 骨位、Roll 与控制链 | 回到骨架层核对枢轴与空间，重做骨架验收 |
| FK 动作正常，IK 出现翻转、跳动或空间切换漂移 | IK 极向、伸缩开关与约束驱动 | 隔离对应控制，核查 ORG/MCH/DEF 实际响应 |
| 骨骼轨迹合理，但局部蒙皮随不该控制的骨头拉扯 | 消费权重与多骨支持域 | 联合排查相关骨组与接缝点，做有保护的选骨局修 |
| 多姿态主支持合理，深屈曲仍缺局部体积或自然开合 | 变形表达与姿态修形层 | 评估保体积开关、Corrective Smooth 或姿态形态键 |
| 顶点位置正常，但表面出现黑缝、硬边或异常高光 | 修改器顺序、求值三角对角线与法线 | 对比原 RAW 与求值法线，按需隔离局部三角化或法线 |
| 身体动作正常，只有衣物、饰品或发片穿模拉扯 | 该部件的绑定策略、转权源与碰撞 | 复查部件转权供体、距离上限、刚性归属或碰撞集合 |
| Blender 内观感正常，导入游戏引擎后变坏 | 导出预算、影响数裁剪、轴向与采样 | 在目标引擎读取器里定位差异，保住 Blender 高保真源 |

### 睫毛与嘴唇的人工交接

睫毛和嘴唇的微距粘连、细微穿插或局部尖褶默认交给人工精修。自动初绑发现这两处问题时，记清工作副本路径、对象名、动作名称、具体帧号及局部对照图，在交付清单和 `manual_handoff` 里标明「待人工修复」，继续完成身体、其他部件与冷开验收。镜头特写需要用到这两处时，由人工修完再用同一动作帧复验。

## 选骨局修、同骨架迁权与作者返工

确认需要修权重时，按“最小写入域、保护非目标、成对查接缝”的纪律操作：

- **选骨局部重算（`rigging-workflow candidate-selected-skin`）**：
  1. 先跑 `inspect`，显式指定目标网格与至少一根变形骨（省略 `vertex_indices` 时工具自动圈点，可用 `radius_scale` 调范围）。
  2. 重点查看返回里的 `coincident_boundary_pairs`：它列出选区两侧坐标重合的 UV/分件拆点。遇到接缝处把成对拆点一并纳入写域，避免弯折时接缝张开。
  3. 同一工程需要联动修改多件网格时，在 `targets` 列表里逐件写明 `target`、`proxy`、`candidate_name` 与点域，全部预检通过后一起执行。
  4. 跑 `execute` 在新审片副本写入结果，未选中的骨组权重逐项原样保留。配置 `verification_frames` 在中立、中段、峰值与复位态实测拆点间距，确认为 0 毫米拆缝再采用。
- **同骨架供体迁权（`rigging-workflow candidate-skinning-policy`）**：已有角色需要把同骨架一份成熟权重迁到目标局部时，依次运行 `qualify` → `plan` → `preview` → `apply`，先看逐点非零差异与作用范围，再写入新候选；同时把逐点差异、动作帧和视口范围图一并交下游。
- **作者返工与旧绑重建（`rigging-workflow candidate-repair`）**：接续旧作者返工、重建兼容绑定或原骨架逐点修权时，先跑 `inspect` 与 `review-handoff` 核清源/目标骨映射、受影响点数与组锁，审核通过后再 `apply`。
- **肩胯肘膝局修与镜像配对**：先列出支持核心、过渡带和保护外环，明确可写点、可写骨组与供受体关系；定量重分配后再在写域内适度平滑，左右对称区域成对检查并保持一致。遇到同方向连续两轮看不出肉眼改善，立即切换更成熟的路线（如退回检查骨位、改用姿态修形或退回建模补环线）。

## 显式局部辅助骨与局部拓扑边界

- **局部辅助骨**：数字辅助骨用来表达软组织鼓起或衣料桥接。把规格写进参考配置后走正常生成与骨架双审；EditBone 先写非零 head/tail 再赋 matrix 与 length；同供体平移辅助骨采用单段主 DEF 为父、与供体同位同轴、关闭时局部 basis 为单位矩阵。配权前把相机可见的病灶三角反投影到实际网格，确认真正可见的病灶顶点全部落在支持域内；采用逐供体让渡台账从指定主骨让渡权重，并做「完整 Primary OFF / Helper 0 / Helper ON」三列同机位对比。搭建双端多段 B-Bone 桥时，牢记 `Bone.bbone_easein/out` 的 Rest 值 1 与 `PoseBone` 偏移值 0 属于不同层，写入 Pose 通道保持 0 偏移。
- **局部拓扑重建边界**：确实需要局部修面时，按真实面邻接划定完整区域与保护外环。使用 Grid Fill 后同时核查三视外轮廓、边标记和自定义法线（用存活的 `BMVert`/`BMFace` 对象映射保留域外法线扇，重算新面法线后检查 `normals_split_custom_set` 是否新增锐边标记）。改动网格拓扑后，把新副本作为独立手工修改版本，重新过受影响的骨架检查再做权重处理。
