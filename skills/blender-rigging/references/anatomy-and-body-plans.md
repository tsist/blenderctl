# 变形原理、解剖与身体方案

制作新角色、陌生生物或复杂机构绑定前先读这一份。先理解运动规律与组织职责，再决定骨架层级和变形方式；靠模板默认位或自动权重碰运气，后面返工成本远高于前期摸清结构。

## 动手前先补齐陌生领域的知识

首次接触陌生解剖、材料、机械结构、运动接触或目标引擎时，先完成只读取证与小步学习，再动生产模型：

1. **把未知拆成具体问题**：问清“这根轴绕哪里转”“袖笼有没有活动余量”“风由骨链还是材质驱动”“减面删骨后挂件挂在谁身上”，带着问题去查资料。
2. **找对依据**：API、字段与数值语义核对当前版本官方文档或源码；运动规律与视觉形状参考高质量教程、原作者拆解工程与成熟成品。分清宣传摘要、字幕和实跑工程的可靠程度。
3. **写清四项决策**：对每个活动部件记清「允许怎么动 → 挂在谁身上 → 由哪一层变形 → 用什么真实动作验收」。已有成熟结论直接复用；遇到机制拿不准时，在隔离小样上做单变量验证，结论清晰后再进入正式工作副本。
4. **把有效经验沉淀下来**：任务进度记回当前车道状态，跨作品通用的工艺与反例整理进技能参考或共享 Wiki，大型对照图与回执留在任务审计目录。

## 变形机制选型：按运动职责挑最轻方案

骨架本质上是运动与变形的参数化表达，职责是准确表达枢轴、弯扭伸缩、支撑接触和组织相对运动。按用途选够用的表示，再做局部精修：

| 方法 | 擅长解决的问题 | 需要同步核对的边界 |
|---|---|---|
| 骨父级、刚性约束或刚性单骨权 | 整体随动、抓握佩挂、硬壳铰接 | 核对连接点、父逆矩阵、局部朝向、非均匀缩放与空间切换瞬间 |
| 普通归一化 LBS 蒙皮 | 平滑混合可编辑的骨骼运动 | 核对实际消费矩阵、多骨支持域、弯折压褶与多姿态兼容性 |
| 保体积混合（DQ / Preserve Volume） | 减轻轴向大扭转时的糖纸塌缩 | 核对大角度外侧鼓包与相邻关节观感，用同输入实面做 A/B 对照 |
| Twist 分段骨 / B-Bone / 局部辅助骨 | 均匀分摊前臂扭转、连续曲线弯折或独立局部鼓起 | 核对完整 B-Bone 段句柄、开关对照和真实消费路径 |
| 形态键与姿态驱动修形（PSD） | 面部表情、风格化变形、补齐骨骼混合后的姿态残差 | 核对中立基线、中间帧、多轴组合插值与驱动表达式有效性 |
| 笼形与表面传递（Mesh / Surface Deform） | 用简洁控制笼驱动高密或分层复杂表面 | 核对控制笼权场、绑定有效性、层间距离与最终生产表面 |
| 肌肉、布料、软体与骨动态 | 惯性晃动、衣摆重力、真实碰撞反馈 | 核对基础锚点、真实碰撞集合、求值顺序、磁盘缓存与导出兼容性 |

### 读懂权重的真实能力

- **权重混合已有响应**：普通归一化 LBS 按各变形骨的相对比例混合顶点变换，权重跨所有动作共享。遇到错误关节枢轴、缺失自由度或独立形体变化，先修骨位、控制链或补专门修形层，再调权重过渡。
- **区分各类顶点组**：骨骼变形消费组、固定点（Pin）组、碰撞组、修改器遮罩组各自承担不同语义。编辑时按需选择保持原总和或局部归一化，把编辑规则与目标引擎导出裁剪分开处理。
- **结合运动职责看小权重**：判断胸壁顶点该跟躯干还是前臂，看真实骨骼运动与表面拉扯效果，长距离柔顺衔接往往需要合理的小权重过渡。观察时同时看多骨支持与组合和，区分原始 RAW 权重、Lock Relative 与 Multi-Paint 显示语义。
- **骨轴与拓扑分别排查**：Blender 骨长轴固定沿 head 指向 tail（局部 Y），Roll 决定其余局部轴与弯曲平面。确认实际求值矩阵和弯曲方向，保护已绑模型的原有变换与父逆矩阵。关节处提供足够的弯曲环线，把法线问题与蒙皮穿插分开处理。

## 跨物种身体方案速查

先辨认前向、背腹、左右、重心根、支撑端与附肢，跟踪「身体基底 → 关节或连续段 → 末端接触」的传动链，按真实生物或机构规律选结构：

| 身体方案 | 核心运动职责 | 推荐骨架与控制表示 | 重点检验姿态 |
|---|---|---|---|
| 人形与近人形 | 骨盆重心、躯干弯扭、肩带与上肢、髋膝踝足、头颈手面 | 用途适配的 FK/IK、明确变形骨，按需加 twist 与修形 | 蹲起转身、大幅抬臂、弯肘旋腕、握持与足底支撑 |
| 犬猫等趾行四足 | 肌肉悬吊肩胛、胸廓相对滑动、后肢膝跗趾三段联动 | 对应肩带、脊柱、骨盆与四段爪控制 | 迈步摆动、低位支撑、拱背转弯、内腋与尾根衔接 |
| 马牛等蹄类 | 长肢多活动段、球节与系部缓冲、刚性蹄壳 | 多节或耦合 IK/FK，硬蹄与软组织分域 | 支撑离地、屈折方向、蹄壳保形与系部活动 |
| 熊等跖行类 | 足底全掌与足跟接地、较长前肢与躯干侧摆 | 按真实足底比例定肢体链与落地支点 | 典型步态、抬足站立与转体接触 |
| 爬行与两栖 | 外展四肢、脊柱侧波、跳跃或攀附收放 | 按物种步态定制肢体与脊柱控制 | 爬伏转弯、起跳收腿、腹侧贴地间隙 |
| 鸟翼 | 肩肘腕手折叠展收、初级飞羽属手与次级属前臂 | 主翼关节链配主羽控制与插值覆盖 | 全展半收、上下扑动转折、羽根稳定与层次覆盖 |
| 蝙蝠翼膜 | 指腕肘与体侧腿尾多锚点张拉、弧面收折 | 多锚点骨与表面修形，按需加柔体 | 展收、弯指、倒挂中的锚定与折痕 |
| 鱼与鲸豚 | 鱼以侧向体尾或鳍推进，鲸豚以背腹尾摆为主 | 按主弯曲段建体干连续链，鳍片鳍条分域 | 主弯曲波传播、头体稳定、转向与尾根过渡 |
| 蛇形与长躯干 | 中心线波形迁移、贴地推进与抬头 | FK、曲线或分段链，接触点单独管理 | 波形向前传递与贴地段衔接 |
| 触手与象鼻 | 局部弯扭、伸缩截面积变化与吸附抓取 | FK/IK、Spline IK、B-Bone 或柔体近似 | 根部衔接、弯曲迁移、扭转、抓放与吸盘朝向 |
| 节肢多足与外骨骼 | 硬节段保形、柔性关节膜与多足相位支撑 | 刚性分域加软连接，各肢独立 IK/FK | 支撑相位、甲片净空与壳体保形 |
| 机械闭链与混合体 | 精确关节轴、耦合连杆、基座与末端工具偏移 | 刚性变换、约束与 FK/IK，软缆另分软域 | 单轴行程、闭环闭合、可达极限与刚性保形 |

## 人形重点区域制作要点

- **根、骨盆与躯干**：把世界移动、重心倾斜和皮肤弯扭职责拆开。下蹲、转身、迈步时检查肢端与胸盆联动，出现整体漂移先查父级层级和 Action 空间。
- **肩带三关节（SC / AC / GH）**：胸锁关节（SC）在胸骨上端前侧，肩锁关节（AC）在肩峰处，盂肱中心（GH）在肩峰下方。锁骨从 SC 连至 AC，肱骨从 GH 伸向肘部，保留 AC 到 GH 的真实空间偏置。需要大幅举臂时，加入独立肩胛载体表达上回旋与前后倾，同机位用正背侧顶斜向实面叠骨核准后再生成。
- **肘、前臂与腕**：区分主屈伸轴与前臂旋前旋后扭转；在弯肘配旋腕和持物姿态里观察体积收缩，确有明显扭结再加前臂扭转分配骨。
- **髋、臀与膝**：内部髋关节中心位于骨盆深处，与体表大转子位置区分开来；抬腿、深蹲、弓步和转髋时一起检查前裆、臀后轮廓与膝窝压缩，保留自然的宽压褶并消除异常尖折。
- **踝、足与鞋**：分清踝关节转轴与足跟、前掌、趾端滚足支点；裸足、硬底鞋和高跟鞋各自匹配对应静置姿态和地面支点。
- **手与面部**：精细握持配齐掌弓、拇指对掌与指节控制；远景角色可用简化手掌。面部按需选用骨骼、形态键或混合路线，把眼球与牙齿刚性跟随、眼睑弧面闭合、唇边封口分别验收。

## 四足与连续附肢补充要点

- **陆生四足**：后肢外观朝后弯的关节多为跗关节（Hock），真正的膝关节（Stifle）贴近腹侧；犬猫肩带靠肌肉连接胸廓，检查肩胛相对胸廓的滑动和前肢承重。参考成熟成品（如 Blender Studio 的 Autumn）时，先拆清真实消费链（控制笼、修改器顺序、方向修形层），按组织区域借鉴思路。
- **连续附肢与曲线链**：使用 Spline IK 时明确链长模式、均匀分段、曲线半径与 Y/XZ 缩放规则；使用 B-Bone 时核清段数、句柄类型与弯曲映射，再检查端点抓取与贴地职责。
