# PBR 通道契约与分层规范

本页讲清 PBR 物理标尺、各通道的 Blender 接线与色彩空间约定，以及多图层组装时的实战经验。回到主入口见 [SKILL.md](../SKILL.md)。

## 1. 物理标尺与通道契约

所有材质在统一的中性展示灯光下校准，把材质本身物性与镜头气氛打光分开。

| 通道 | Blender 色彩空间与接线 | 物理标尺与验收要点 |
|---|---|---|
| BaseColor / Albedo | `sRGB` -> `Base Color`（线性源另作声明） | 画面无方向光、阴影、高光和 AO；非金属反照率控制在 `30–240 sRGB` 之间（炭黑不压死纯黑，白漆不过曝纯白）；金属区域填导体反射色 |
| Roughness | `Non-Color` -> `Roughness` | 按微表面结构独立表达粗糙分布（黑更光滑、白更粗糙）；保持与 BaseColor 独立，避免把彩图明暗直接当粗糙度 |
| Metallic | `Non-Color` -> `Metallic`（或常量 `0` / `1`） | 清晰区分裸金属（`1`）与漆层、锈蚀、陶土等绝缘体（`0`）；过渡灰值留给明确半覆盖边界 |
| Normal | `Non-Color` -> `Normal Map` -> `BSDF Normal` | 统一采用切线空间（`TANGENT`）与 OpenGL `+Y`；显式绑定目标 UV 层；优先用真实烘焙产出，接好后用白底开关对照检查高光方向 |
| Height | `Non-Color` -> `Bump`（或真实几何置换） | 记录中性零位、符号、位深与真实物理幅度（如米制 `height_distance`）；程序化导出为有符号 32 位浮点 EXR；已烘进最终法线的起伏在重建时直接连 Normal，保留 Height 作辅助交付 |
| Alpha / Opacity | `Non-Color` 标量或真实 RGBA Alpha -> `Alpha` | 白（`1`）不透明、黑（`0`）透明；检查剪切/混合模式、阴影与边缘晕边；玻璃透射改用 `Transmission` |
| Transmission / IOR | 标量 `Non-Color` 或常量 -> `Transmission` / `IOR` | 玻璃保持 `Alpha = 1`，按真实材料选 `IOR`（常见玻璃约 `1.45–1.52`），用 `Roughness` 区分清玻璃与磨砂玻璃 |
| Coat | 标量 `Non-Color` 或常量 -> `Coat Weight` / `Coat Roughness` | 用于清漆、釉面、车漆等清透表层；开启釉层或清漆时，同步核对 `Coat Normal` 连接，确认表层起伏符合工艺意图 |
| Complex Mask | `Non-Color` -> 指定图层混合权重 | 用图像、几何或程序信号驱动，写清空间成因（受潮、摩擦、积灰、剥落）与物理尺度 |
| AO | `Non-Color` -> 指定旧化遮罩或目标引擎槽位 | 区分局部几何烘焙与场景遮挡；避免盲目乘进 BaseColor 压黑暗部；高低模投射的局部 AO 适合驱动凹处积灰 |

## 2. 通道清单登记项

在进入组装前，用一份简短清单对齐所有通道：
- 对象名、材质槽、目标面域与 UV 层名。
- 分层顺序（`基材 -> 覆盖层 -> 旧化层`）、每层来源类别（`constant / image / procedural / hybrid`）与开关状态。
- 每个通道的图像路径与 SHA256（或程序 `signal` ID 与 `seed`，或常量值与单位）。
- 色彩空间、物理覆盖尺寸、法线空间方向与输出位深。

把清单作为制作依据和交付记录；向 CLI 提交严格 JSON 请求时，按 `material describe --schema` 只映射合同允许的字段。

## 3. 分层组装的实战经验

1. **先分清材质颜色与覆盖边界，再调粗糙度**。遇到多层材质质感趋同或反光发灰时，先隔离各层 BaseColor、遮罩边界与沉积层，确认底材和覆盖层各自有独立色域与反射，再微调 Roughness 与 Coat。
2. **显式决定宏观起伏是否跨层共享**。当不同材质层通过完整 BSDF 混合时，上层接管着色会盖掉下层独立起伏。同一基体上的连续雕饰、釉层断口或浅浮雕，应让外表面各层共用同一张宏观 Normal 或统一 Height 场、同一 UV 与同一幅度，确保覆盖层接管后立体轮廓依然连贯；各覆盖层自身的微颗粒则留在各自独立通道里。
3. **区分着色凹凸与真实几何厚度**。Bump 与 Normal 负责表面微起伏与浅台阶观感；一旦镜头要求真实剪影、自遮挡或厚壁侧缘，回建模阶段做真实几何厚度或细分支撑。
4. **连接优先于常量，改参前先读回实例**。Roughness、Metallic 等插槽接上贴图或程序信号后，面板常量会被覆盖；改贴图结果时走对应缩放/偏移控件（如静态图层的 `adjustments.roughness_scale/bias` 或程序化信号 `remap`）。修改节点组接口默认值后，同步读回实际材质实例确认已生效。
5. **内外表面与接缝分域管理**。器物外腹、口沿、内腔与底足按各自朝向和 UV 独立分域，内壁接缝与外壁接缝分开定位。检查内腔时布置能看清深处的专用机位与临时诊断补光，发现接缝硬线时用单通道隔离定位到具体是 BaseColor、Roughness 还是 Height 边界再精准修复。
6. **清扫无用孤立图像引用**。增量替换贴图容易残留未被引用的旧图像数据块；正式交付前核对实际引用闭包，需要干净交付时从受保护源副本重新组装，保持依赖列表精确透明。
