# 参考定标与原生生图

本页管开工前的参考筛选、质量简报冻结，以及选用图像或混合路线时的原生生图、母版配准与图像门卫检查。回到主入口见 [SKILL.md](../SKILL.md)。

## 1. 先找参考并亲眼看过

每个新材质任务或新增主导材料，动手前先找齐并亲眼打开主参考与关键局部图。用户已经提供清晰参考时直接采用，缺少局部反射或工艺细节时再补找。同一任务里的小调参沿用已冻结参考，只有目标工艺或观察尺度变化时才更新简报版本。

- **最低参考配置**：一份能看清材料身份、涂饰状态与完成度的整体主参考，加一组能看清关键微观或中尺度结构的局部图。清玻璃或均匀涂饰可用一组清晰产品照完成。
- **挑选原则**：优先选同材料、同涂饰工艺、相近新旧程度与观察尺度的参考。剔除模糊、重锐化、强景深遮蔽或后期过重的图片。参考用来定风格、材料层次和完成度，木纹走势、节疤或划痕的具体位置可按模型自然组织。
- **常用参考起点**：

| 来源 | 适合观察的重点 | 使用前核对 |
|---|---|---|
| [Poly Haven](https://polyhaven.com/textures) | 真实扫描表面、微结构层次、物理覆盖与成套通道 | 打开具体资产页看原尺寸预览与物理尺寸；资产许可与站点条款分别确认 |
| [ambientCG](https://ambientcg.com/list?type=Material) | 多种扫描与程序材料、PBR 通道分工与预览 | 核对资产制作方式、分辨率与通道语义 |
| [cgbookcase](https://www.cgbookcase.com/textures) | 常见表面细节、磨损与污渍层次参考 | 核对页面许可、原始清晰度与法线方向 |

每份参考在简报里写明用途：`style_quality_reference`（风格与质量指导）、`production_texture`（直接进入材质生产）或 `both`。用作质量参考时看清晰合法预览即可；实际导入工程作生产贴图时，再完整核对许可、通道编码、物理尺寸与文件 SHA256。

## 2. 冻结可观察的质量简报

开工前在任务目录复制 [material-quality-brief.template.json](../assets/material-quality-brief.template.json) 填好 `material-quality-brief.json`（或等价 Markdown），记清 `brief_id` 与修订号，作为后续每轮看图对照的固定标尺。

简报覆盖以下内容：
- **目标与条件**：材料、涂饰、新旧程度、真实尺寸、目标引擎、正常展示距离、最近检查尺度与交付分辨率。
- **参考登记**：参考 ID、页面 URL 或授权本地路径、实际看过的整体与局部范围、选用理由与用途。未知尺寸或光照如实填 `unknown`。
- **七维可观察标准**：为每个维度写清 `reference_ids -> expected_observation -> inspection_view -> rejection_condition`，把通过线写成肉眼可辨的现象，同时写明允许自由变化的局部（如随机 seed 与瑕疵落点）。

| 维度 | 重点观察什么 | 返修信号 |
|---|---|---|
| 材料身份与风格 | 正常展示下的色域、反射、涂饰与新旧感属于目标材质类别 | 像笼统的纯色塑料块、木像塑料、漆像裸金属、玻璃像粉蜡 |
| 宏观组织 | 主纹理方向、区域分配、旧化成因合理，多部件尺度统一 | 木轴方向错乱、端面断裂、无依据满面脏污、各部件花纹尺度漂移 |
| 中尺度结构 | 纤维、晚材、漆层边界或氧化斑块在中近景层次分明 | 只有单层基础噪声、等距高对比条纹、明显平铺重复 |
| 微表面与反射层次 | 近景与掠射光下，微孔、细纤维、涂层起伏与粗糙度变化有合理解释 | 各通道照搬同一噪声、靠夸张凹凸冒充细节、正常视图变砂纸 |
| 物理尺度与采样 | 结构尺寸与 UV 覆盖匹配，烘焙到目标分辨率后主特征依然可读 | 低于像素采样能力产生摩尔纹闪烁，或烘焙后关键细节糊成一片 |
| 表面与区域连续性 | 真实 UV 接缝、倒角、端面、薄壁与内腔过渡自然 | 明显拉伸、接缝硬切、方向突变、每条棱边均匀磨白 |
| 烘焙后质量 | 同机位同灯光下对比可编辑节点版与纯贴图重建版，再查换光与近景 | 大形接近但关键局部消失、重复叠加凹凸、通道缺失或色彩空间错配 |

## 3. 原生生图优先与母版配准

遇到需要特定纹样、文字标识、浮雕装饰、复杂磨损遮罩或照片质感时，进入 `image` 或 `hybrid` 路线：

1. **优先调用宿主代理原生生图**：按当前会话暴露的原生生图工具执行，每个独立资产、通道或变体单独调用。本地编辑既有贴图前，先解码并查看原图。
2. **先建无光照二维母版**：需要多张配准贴图时，先生成无方向光、无阴影、无高光的二维基色或布局母版，固定横纵方向、物理覆盖、UV 接缝轴与区域锚点。后续各通道图和遮罩都以这张母版为基准编辑派生，保持空间逐像素对齐。
3. **写清通道提示要点**：
   - 写明是平面纹理图，边到边充满画布，无产品轮廓、无文字边框水印；明确水平周期平铺或双轴平铺。
   - 写明母版位置与形状严格保持，写清目标通道的编码含义：Roughness 标明黑白对应光滑与粗糙，Height 标明中性灰零位，Normal 标明切线空间 OpenGL `+Y`；可靠切线法线优先通过真实烘焙生成，图像候选须单独做白底开关对照核验。
   - 区分 Alpha 标量遮罩图与真透明 RGBA 图；需要真透明时开启透明背景参数并检查 Alpha 通道。
4. **原生受阻时的回退**：只有遇到限流（429）或服务不可用等真实故障时，才转用已授权的备选生图技能，沿用同一提示词、参考链与尺寸预算，记清故障时间、原因与服务差异；原生恢复后新生成回到原生工具。

## 4. 图像门卫与文件管理

生图输出及时复制到本任务持久目录，按版本命名，把源图、生产数据图与有损预览分开存放。每次查看或入库前运行 [image_gate.py](../scripts/image_gate.py) 检查解码、宽高与字节数：

```powershell
python './.agents/skills\blender-material-authoring\scripts\image_gate.py' `
  '<图像绝对路径>' --purpose preview --report '<本批审计>\image-check.json'
```

- **尺寸与体积门线**：生产生成图最长边控制在 `2048` 像素以内；会话看图预览单张控制在 `2 MiB` 以内。
- **预览副本分离**：大尺寸无损 PNG/EXR 原件保留在生产目录，看图时另输出 768–1024 像素、质量 90–95 的 JPEG 预览副本，向看图工具传入 `.jpg` 路径；所有法线、粗糙度、高度与遮罩数据始终使用无损生产原图。
- **来源与授权登记**：记录每张生成图或外部图的工具、输入参考链、许可类型与拟交付用途，方便交付前按用途核对清权范围。
