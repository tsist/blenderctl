# 视觉迭代、三方对照与交付清单

本页说明材质从首轮预览到最终放行的看图节奏、三方对照方法、按用途裁剪的验收项与交付封包要求。回到主入口见 [SKILL.md](../SKILL.md)。

## 1. 由大到小的看图迭代

每次迭代固定模型、机位、中性灯光、曝光与色彩管理（如 `AgX`），围绕一个主要假设做改动，保存前后图对照。

1. **缩略图先定大局**：先渲 `256–384` 全帧图对照冻结参考，确认材料身份、色块比例、主纹理方向和旧化分布成立。正常展示距离都看不出目标材料身份时，优先修来源、遮罩、尺度或层结构。
2. **原尺寸局部抠细节**：大形成立后再渲原尺寸近景，重点查颗粒与纤维粗细、裂纹边界、UV 接缝、端面、倒角、薄壁以及玻璃口沿和内腔。
3. **通道隔离快速归因**：
   - 颜色发灰或质感趋同：切仅 `BaseColor` 图，检查反照率区间（非金属 `30–240 sRGB`）和各层遮罩是否串色。
   - 立体感弱或高光方向反：切白底仅 `Normal` 开关对照，核对切线空间 OpenGL `+Y`、强度与是否被上层盖住。
   - 反射发死或油腻：切常色平面仅 `Roughness` 图，确认粗糙度独立分布且与目标表面状态匹配。
   - 磨损或积灰不可见：单独输出最终遮罩并做图层开关对照，排查阈值过窄或被连乘压成全零的问题。

执行看图评审时，先亲眼打开新渲染的预览图（JPEG 副本控制在 2 MiB 以内），把七个质量维度逐项记为 `met`、`gap`、`not_observed` 或 `not_applicable`；存在关键 `gap` 时继续返修对应信号、贴图或 UV。

## 2. Cycles / EEVEE Next / 纯贴图重建三方对照

材质作者版满意后，把导出的贴图放进正式目录，只用这些磁盘贴图与声明常量在干净工程里重建材质，另起进程冷重开。在完全相同的机位、中性柔光、掠射斜光和换光条件下，并排对比三组画面：

| 对照对象 | 重点核对什么 | 处理方式 |
|---|---|---|
| Cycles 可编辑节点版 | 作为物理质量基准，核对材料身份、宏观/中尺度层次、微表面反射与玻璃厚壁透射 | 视觉差距先修作者版，确认达标再导出贴图 |
| Cycles 纯贴图重建版 | 核对导出贴图是否保留主特征、无重复叠加 Bump、无通道丢失、无 `sRGB / Non-Color` 错配 | 关键局部丢失时检查 UV 密度、采样分辨率或通道编码并返工重烘 |
| EEVEE Next 渲染版 | 核对实时视口与双引擎可用性，重点查金属高光、薄面端纹滤波、透明排序与厚壁玻璃透射 | 玻璃发黑时核对 `SLAB` 厚度与光线追踪设置；如实记录双引擎差异供下游参考 |

## 3. 按交付用途裁剪验收重点

| 交付用途 | 除三方对照外重点落实 |
|---|---|
| 可复用资产 / 产品静帧 | 整体多角度、关键近景、必要接缝与内腔图；正式目录冷重开重渲；可编辑版与纯贴图重建版并排交用户审看② |
| 游戏实时资产 | 在目标引擎实机导入检查切线方向、贴图压缩与 mipmap、Alpha 排序/剪切、显存与帧耗 |
| 影视 / VFX | 目标镜头距离下的线性数据精度、16/32 位深、UDIM 与真实置换、AOV 通道与流水线输出 |
| 动画 / 风格化 | 运动镜头下高频纹理、高光与 Alpha 边缘的时序稳定性，排查闪烁与摩尔纹 |

分项记录技术检查、视觉对照、性能开销、时序稳定、依赖复现与来源授权状态，把用户审美反馈单独登记，便于后续返修追踪。

## 4. 正式目录冷重开与交付包清单

1. **检查外部依赖闭合**：复制到最终正式目录前，核对实际引用的贴图清单，确认无本机临时缓存路径、无丢失贴图、无数据贴图误标 `sRGB`。需要自包含打包版本（`Packed`）时，移到无外部贴图的隔离目录重开重渲复查。
2. **交付包标配内容**：
   - 可编辑节点主工程 `.blend`（路径与 SHA256）。
   - 导出贴图文件夹（全部使用相对路径）与纯贴图重建验证工程 `.blend`（路径与 SHA256）。
   - 质量简报 `material-quality-brief.json`、通道清单（含对象、材质槽、UV 层名、色彩空间、位深、常量与来源授权说明）。
   - 三方对照图（整体、近景、换光）与复现请求 JSON。
   - 明确列出的已验证项与待验证项（例如目标游戏引擎实机导入或动画时序测试）。
3. **转交下游**：用户通过「审看②（最终材质）」后，可复用资产转 [blender-asset-manager](../../blender-asset-manager/SKILL.md) 执行规范命名与入库；角色或镜头资产按工序转绑定或镜头与灯光部门。
