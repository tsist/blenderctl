# 先找参考，再定义材质质量

本页是所有材质来源的共同开工与验收要求，适用于constant、image、procedural、hybrid以及DeepSeek执行。参考用于指导材料身份、风格、工艺、细节层次与完成度；木纹走向的具体曲线、节疤/锈斑/划痕的逐处布局不要求一致。它不改变按需求选择来源的规则。

## 1. 每次任务先建立参考依据

每个新材质任务或新增主导材料，都要主动寻找、筛选并实际查看合适参考，再开始正式材质创作。用户已给出清楚参考时先采用，缺少的局部/反射/工艺证据再补找。可从项目已授权参考库重新选择适用素材；必须记录本次选择理由并重核观察尺度，不能只说“沿用经验”。同一任务内的小调参沿用冻结参考，目标/工艺/观察尺度改变时再更新，不要求每改一个参数重新上网。

最低证据是：一份能判断材料身份、表面状态和完成度的主参考，加上足以判断关键细节的局部依据。可以来自同一高质量资产的整体与局部，不强制凑不同网站；清玻璃/均匀涂饰等可由足够清晰的一组产品照完成。主导材料不同应分别有适用依据。

实际打开原页面、可辨图像或授权本地参考，并查看与任务有关的局部。搜索摘要、文件名、低清缩略图、只有URL或“看过类似作品”不能作为已观察证明。网页能读出文字但图像不可见时，记录未观察，继续找可观察来源或请求主代理提供参考包。

优先寻找同材料、同制造/涂饰工艺、相近新旧程度和观察尺度的对象。先选正确材料与工艺，再比完成度；不能用粗糙旧木参考验新清漆木，或用厚锈表面要求干净喷漆。通常先比较少量候选，淘汰模糊、重锐化、过强后期、景深遮蔽、无局部或不匹配的参考；记录采用理由与关键不适用部分，数量本身不是门槛。

## 2. 材质网站与素材的用途

可从这些入口寻找贴图/扫描材料及其预览：

| 来源 | 适合寻找的证据 | 使用时要核对 |
|---|---|---|
| [Poly Haven](https://polyhaven.com/textures) | 扫描表面、细节层次、物理覆盖与成套通道 | 具体资产页、尺寸、原始预览/局部；[资产许可](https://polyhaven.com/license)与网站/API条款分别判断 |
| [ambientCG](https://ambientcg.com/list?type=Material) | 多种表面、扫描/程序制作方法、PBR通道与预览 | 具体资产和制作方法、尺寸/通道；[许可说明](https://docs.ambientcg.com/license/)覆盖资产与站内材质预览 |
| [cgbookcase](https://www.cgbookcase.com/textures) | 材质及表面细节、磨损/污渍素材参考 | 具体页面/许可、原始清晰度、Normal方向等通道语义，不能照搬旧教程接口 |

入口只是搜索起点，不保证每个资产适合当前目标。允许其他有据的真实材料/工艺照片、优秀CG作品和用户风格图。分别记录它们回答的是“真实材料是什么”“目标风格/完成度是什么”还是“通道结构如何组织”。单张漂亮球渲染不同时证明尺寸、无光照底色、真实粗糙度或目标模型上的效果。

每份参考注明用途：`style_quality_reference`（观察/质量指导）、`production_texture`（实际进入材质）或`both`。本任务默认前者；找到贴图并不意味着必须贴到模型，也不意味着需要复刻其图案。若实际导入、采样、裁切作生产数据或随工程分发，则进入image/hybrid输入契约，核对具体用途许可、通道/色彩/法线/尺度和资源SHA。公开可看、免费下载、可生产使用与可再分发分别判断；网站/API服务条款与资产许可也不混写。不读取账户凭证，不为找参考擅自安装工具或购买素材。

无需下载整个大分辨率材质包来“证明找过参考”。先用足够清晰的合法预览/局部；需要原通道判断结构时才获取所需文件，按可用下载流程保留来源和文件身份。参考外发给子代理时也要符合其可用范围。

## 3. 把“高标准”写成可观察的质量brief

开工前在本任务目录保存`material-quality-brief.json`或等价Markdown，可从[模板](../../assets/material-quality-brief.template.json)填写。它是审阅计划，不是插件manifest，不把这些字段塞进严格制作请求。记录brief_id、revision和冻结时间，保留冻结版，并将其路径/SHA记在独立检查点或审阅回执中，不向同一JSON写入自身SHA。冻结后才据它选模板/配方；目标变更新建revision，记录原因及原任务授权/新增接受依据，保留旧版。不得看到成品不足后另挑更低标准参考来放行；补充更清晰证据也要记录版本与理由。

brief至少记录：

- 目标材料/涂饰/新旧程度、风格及用途，实寸、目标引擎、正常展示与最近检查尺度、交付分辨率。
- 参考id、具体资产/页面URL或授权本地路径、作者/站点、查看日期、实际看过的整体与局部（文件有SHA或页面截图/裁切位置），选用理由、来源类型和用途。未知尺寸/光照/校准写unknown，不从球渲染精确反推物性。
- 从参考提取的材料身份、主方向/宏观组织、中尺度特征、微表面及反射响应；每项明确`reference_ids → expected_observation → inspection_view → rejection_condition`，并注明为何需要、是否为关键通过项。
- 可以不同的部分，例如节疤/斑块位置、非指定的细小瑕疵布局、随机seed；不得把这些列为相似度目标。需要特定图案/标识时另按用户要求，不由本页放松。
- 固定比较条件和当前最重要差距；过程状态与最终审阅者。把自评、主代理视觉判断和用户反馈分开。

下面七个质量维度都须留判断行，相关维度再拆成具体可观察项，不能只填写“材料身份”而略过中/微细节。不是每种材料都要有脏污或强起伏；关键特征必须来自需求和适用参考。把无关维度或特征标`not_applicable`时解释原因，不能把缺失/看不见的必要特征随意改成不适用。

## 4. 细致度的实际检查

| 维度 | 需要的观察证据 | 返工信号 |
|---|---|---|
| 材料身份与风格 | 正常展示时颜色范围、反射、涂饰及新旧程度与目标参考属于相同类别/质量方向 | 只像“一块棕色”“一层灰色”、木像塑料、漆像裸金属、清玻璃像粉蜡 |
| 宏观组织 | 主方向、区域分配和成因合理；同物体部件尺度一致 | 木轴错、端面断裂、无依据满面旧化、各部件花纹尺度漂移 |
| 中尺度结构 | 目标纹理、纤维/晚材、漆层边界或氧化组织，在约定中近景能辨出有层次的变化 | 只调基础色与单层Noise、等距高对比条纹、重复盖章、破碎图案浮在表面 |
| 微表面与反射层次 | 近景/掠射光下，参考相关的细纤维、孔隙、涂层微起伏或粗糙度变化有可解释贡献，并保持合理幅度 | 所有通道复制同一噪声；靠夸张Bump、锐化、污点使细节“可见”；正常展示变砂纸 |
| 物理尺度与采样 | 声明结构尺寸/相对尺度及依据；按实际UV覆盖和最近屏幕投影检查烘焙后可读性 | 8K参考细节直接承诺在2K保存、低于采样能力的高频闪烁/摩尔纹或细节全被过滤 |
| 表面与区域连续性 | 检查真实UV缝、倒角、薄面/端面、接触区域；需要内腔时能看见 | 拉伸、接缝、方向突变、区域mask实际无效、每条边同样磨白 |
| 烘焙后质量 | 同条件比较作者与重建，再看必要换光和局部；目标特征仍成立 | 大形相近但关键局部消失、重复Height、丢通道或错误色彩/Normal |

微表面可以主要通过粗糙度/高光表现，不要求每个孔都在BaseColor上显眼。均匀干净材料也可有很高完成度：玻璃先验透射、厚度、反射与磨砂层次，干净漆面先验涂饰与受控微表面，不强加划痕/锈/灰。参考中看得到但目标镜头本不需分辨的微孔，只在其应有反射贡献与约定近景检查，不承诺无限放大。

参考图清晰度、生产图像输入分辨率与最终贴图分辨率分别判断：最终交付2K不要求每份图像输入都原生2K或必须成套PBR。按输入的角色、实际覆盖/UV占比、所需频段、程序化补充和最终观察决定；局部色图/标签或1K色图在适当范围内也可用于hybrid。不能上采样冒充新增真实细节，关键特征的最终采样与质量要求仍须满足。

参考的8K/扫描身份是来源信息，不是本任务统一分辨率规定。采样不足时先查真实尺度、UV密度、投影视角和高频预算；可优化有效采样或改用符合需求的来源。需要改UV/分辨率或超出当前接口时明确交接/范围选择，不擅改受保护UV，不靠增大Noise Detail、Height或过锐颜色伪装质量。约2像素等采样估计只用于发现风险，不能作为审美通过阈值。

## 5. 对照、迭代与通过规则

第一次预览就把**实际参考整体/局部**与**当前候选整体/局部**对应观察：先看材料身份、宏观组织与中尺度，再看微表面、反射和连续性。对参考与候选分别注明尺度/光照差异；不能因背景、曝光或相机不同就做RGB/逐像素相似度判断。参考的细节位置可以不同，但粗细/稀密的分布特性、工艺与反射层次应能解释为何达标。

候选迭代保持模型、机位、灯光、曝光、显示变换与seed等可比条件，围绕具体差距改有作用的信号/通道；改一项主要假设并保留前后证据。必要时用color-only、roughness/normal隔离、层开关和最终mask解释差距，不把技术诊断图当正常展示。不同灯光下的参考只作相应特征指导，不为“看起来一致”反复调光掩盖材质问题。

为每个关键项填写`met / gap / not_observed / not_applicable`、参考id、当前render id/源SHA、简短可见证据与下一步。关键项有gap或not_observed时视觉不通过，不能被平均分、满节点、图数、低误差、文件存在或工具completed抵消。总分和自动相似度可以辅助定位，不能代替逐项判断。新图符合要求时可以不改参数，但必须写出根据；“未迭代”不能只靠第一版自称好看。

作者质量未成立先修作者；烘焙后仍按同一brief验收。预期局部细节在2K重建中丢失时，判断是否仍在**预先允许差异**内；关键特征消失必须返工或明确交付缺口，不把“2K都会变软”自动当放行理由。改变验收目标需保留理由和对应批准/任务范围，不能事后重写通过线。

交付中保留参考清单、质量brief、逐项对照、采用/拒绝候选及原因、实际最终渲染、未通过/未观察项。自评通过后由主代理按同一参考检查关键整体和局部，再按任务接收用户反馈；技术pass和用户审美批准保持独立。

## 6. DeepSeek交接与缺证据处理

委派前给执行者：当前技能入口、质量brief、可访问的参考包/具体页面、明确用途/尺度/引擎、要比较的材料特征与允许差异。执行者须实际看参考和当前新渲染；不能只转述主代理的文字观察，也不能拿模板名或历史案例替代本任务参考。

执行者不能联网时，主代理先完成寻找并提供足够清晰、合法可用的冻结参考包；不能看图时交接参考/渲染身份与未决点。参考或视觉能力不足可以继续模型检查等独立工作，但相关质量项保持pending/not_observed，不静默降低标准。只有文字说明而无足够可观察图像的特征，不得写视觉met。

图片预算包含参考图与候选图。必要整体/局部不能为省上下文而省掉；保留原图和数据图，按当前工具限制制作观察副本、分有限阶段或文件检查点接续。每阶段写清看了哪些参考和哪些候选、目前差距、下一步，不重复塞长图像历史；不能把某次成功的JPEG数量当服务方硬限制。

## 来源与边界

本要求依据用户2026-10-25明确的“每次先找参考，作为风格质量指导、不追求细节一致性”。[Poly Haven纹理标准](https://docs.polyhaven.com/en/technical-standards/textures)对清晰度、无模糊/接缝/克隆痕迹、物理尺寸和去光照有具体要求，可用于挑选参考；其中8K、提交格式和整套通道要求属于其入库规范，不作为本项目统一交付规格。数据图在Blender的色彩空间仍依[通道契约](channel-contract.md)。网站事实核验于2026-10-25；逐资产和具体用途仍需现场核对。
