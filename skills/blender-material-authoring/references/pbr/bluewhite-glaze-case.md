# 釉瓷：法线与反射经验

单件静帧对照的去标识经验；工程/图像、私人反馈和旧审计未公开，不证明物理校准、薄膜、多引擎一致性或通用美术通过。

- 相同底色/法线比较亮釉、缎面、哑光，固定镜头/灯光/色彩/尺度归因参数。
- 常色仅法线与关闭法线对照，色线/阴影不能当凹陷证明。
- Normal 与 Height 不把同结构满强叠加；+Y、UV、强度和 Coat 最终法线分别核对。
- 空间粗糙度图可能覆盖常量，先查连线/scale/bias/诊断，不连续改无效旋钮。
- 调用数下降不等于总耗时下降；生图、人工判断、启动、保存、渲染、恢复分账，GPU竞争影响基准。
- 人工选定后完整视角及正式目录复验；局部图不代作品验收。反馈与未验项保留。

当前插件能力取自实际 Schema 与公开软件验证，不由此案例升级所有材质方法成熟度。
