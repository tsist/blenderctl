# 材质制作：PBR完整规范

所属入口：[Blender材质制作](../../SKILL.md)。本版按材质需求选择来源，旧统一生图前置不再适用；历史案例的输入和效果按其原有范围解释。

## 1. 按材质需求选择来源

先按视觉目标、可编辑性、所需数据精度和现有输入选择constant / image / procedural / hybrid。用户指定来源优先；没有特殊指定时，纯色/均匀物性用常量，可由坐标与几何依据表达的基材和旧化可用程序化，特定图案/文字/语义细节用图像，组合需求用混合。一个材质的不同层、通道可采用不同来源，已有合格图层直接复用。

- **constant：** 没有空间变化的Metallic=0、Alpha=1、IOR等记录明确值。合同要求图片时，用确定性填充或受控烘焙生成文件并验证数值，不为常量调用生图。没有使用的通道标not_applicable及理由。
- **procedural：** 明确坐标、实际尺度、方向、seed、参数和影响通道。木纹、漆面、边缘磨损、凹处积灰、局部锈等可在可验证范围内程序制作；噪声只负责破碎与变化，不能替代使用/接触/高度/朝向/凹凸等分布依据。组合方法先读[基础信号与分层](procedural-signals.md)，具体节点和公共接口见[程序化PBR](procedural-pbr.md)。
- **image：** 需要特定装饰、文字、人物浮雕、照片或已有合格贴图时，保留合法输入及配准。需要AI生图时优先原生imagegen；真实受阻才按可用生图技能和当前用户授权与有效配置条件回退，记录服务、提示词、输入/输出链与错误。选择程序化不依赖生图先失败；选择图像后也不把首次质量差当作静默更换服务的理由。
- **hybrid：** 例如程序木材/金属底材叠加图像标签或装饰，再用几何与程序遮罩定位旧化。分别记录来源、遮罩坐标、配准、通道覆盖及可替换接口，不把彩图转灰冒充独立Roughness/Normal/Height。

没有可靠图像能力而目标包含不可合理程序化的特殊图案时，明确图案区域、目标通道、尺寸、UV/参考和待交接输入；先完成基材与其他已授权部分，相关分支保持pending。不能用无依据满面Noise、删掉图案或降低标准换取“完成”。

**引用的适用边界：** [参考与图像](reference-and-images.md)用于image分支的生成/配准/回退操作；[通道契约](channel-contract.md)说明各来源的读取与输出语义。[验收](acceptance-and-promotion.md)、[实证导航](wiki-and-evidence.md)及历史案例保留2026-10-02时的路线依据，不将其重新当统一生图前置。现行来源决定集中在本节，物性、来源与质量仍分别验收。

## 2. 开工：用途、插件与制作契约

先执行[插件与CLI最高指导](../../../blender-work-methodology/references/plugin-cli-work-units.md)：检查适用插件和后台接口，选择能一批完成图层导入、通道配置、参数设置、保存及检查的工作单元。缺口先评估可复用的受控入口；确需开发时单列目标、成本与验收，不默认扩大当前制作范围；普通小调参可复用现有入口。

确认模型/区域、游戏/影视/动画或静帧用途、引擎和版本、尺寸/单位、观察镜头、透明/置换需求、分辨率与交付形态。输入可从工程与当前任务记录恢复，只询问无法查明且影响正确性的关键输入，不按材料名称代填。定义能观察到的通过与失败现象，不靠“写实”“商用级”形容词验收。插件功能缺口影响正确性或已约定交付时，先明确范围与处理路线。

实际执行读取[插件与CLI材质制作](plugin-cli-authoring.md)。程序化2.0与旧静态图层是不同合同，先describe实际接口；不把procedural参数塞进旧run/batch/study。提前备齐清单、有效旋钮与少量对照，争取一次返回诊断、差异、进度和产物；普通小调参不重建无关输入。

## 3. 参考冻结与几何起点

冻结原创主图、局部材质图、必要视角和来源。先从缩略图识别底色、主风化区域、颗粒/裂纹/涂层尺度、主要光泽，再拆局部结构。记录高质量参考卡、拒绝条件与SHA；生成参考不当真实测量。

固定模型尺寸、相机、正常展示灯光、色彩管理和显示尺度。已有合格白模/UV直接复用；新建时检查拓扑、坏面、翻法线、平滑与厚度，实际查看灰模连续反射。自动平滑核对真实修改器和实例角度，不能以全选Shade Smooth代替必要的Smooth by Angle。标准由模型用途决定，不套用赤陶网格数量。

UV记录方向、覆盖、像素纵横比、实际密度、岛/接缝、内外区域和最小可读特征。瓶口/内壁/底面不能盲目继承外腹高度投影；纹理拉伸先修映射。几何、UV或展示条件有变化就重新核对受影响对照。

## 4. 多通道、分层与清单

冻结坐标、主方向、物理覆盖、UV接缝、区域锚点和可读特征尺度。建立材质清单：对象/槽/区域、基材→覆盖层→旧化顺序、每层来源与开关、遮罩依据、通道的信号或常量、颜色/数据语义、单位/值域、图像身份或seed、目标引擎与输出要求。该清单是意图与证据，提交严格Schema时只投影合法字段。

image分支可先冻结无光照基色/布局母版，再分别制作数据图；procedural分支复用同一空间信号驱动相关通道，分别定义物性变化，不能把同一灰度无差别接入所有通道；hybrid保留图像配准与程序遮罩依据。Normal不能因紫蓝外观就通过，Alpha不能把棋盘格当透明。层之间同一宏观起伏避免重复；已包含Height的最终Normal重建时不再叠一次Bump。

输出按用途列完整通道，而非固定要求所有材料有每一种图。主要为BaseColor/Roughness/Metallic/Normal；Height、Alpha、Transmission、IOR、Coat等按实际需求附图或声明常量。玻璃的Transmission、IOR、粗糙度与Alpha分别保存，Alpha=1不表示没有透射。当前程序化公共export不含AO通道名，不能虚构ao字段；需要AO交付时另查适用入口并单独验收。

原件、可编辑源、烘焙图、重建材质与预览版本化分开。先检查尺寸/字节/解码再看图，生成最长边≤2048，单张会话预览≤2MiB；机械缩小只是工作/预览副本，不改变原件合规性。数据图不以JPEG预览替代。

## 5. 插件组装与公开参数

以通道清单驱动插件/CLI批量加载：确认色彩空间、UV/UDIM、法线方向、标量范围、alpha模式、height路径、引用和材质槽。通道制作契约是意图清单，提交时按当前Schema映射到显式target、layers、bindings与resources，不能将额外元数据直接塞进严格请求。当前插件采用静态贴图及已有明确UV，UDIM/动画/真置换等能力有具体目标时另查验证，不默认已支持。保留基材、区域/沉积、结构、数据解码和输出模块及独立开关；实际实例参数必须读回，节点组接口默认值不等于现有实例值。

旧静态图层的单目标用run，多对象/槽/面清单用batch，同条件有限数值候选用study，复用结构用template-save。程序化/混合用实际发现的procedural-run，导出用procedural-export；受管模板保存以该模式当前接口为准，不假定旧template-save认识2.0。它们保持standalone作业，不未经合同允许塞入DAG。信号/图像连接可能覆盖对应常量；先读真实连接和有效参数，不能反复改无效旋钮。

同一特征只承担一次目标起伏，Normal与Height选择替代或明确频段分工。不同UV域/内壁等区域可用独立实例，共享图像原件；修改共享节点组前确认影响范围。提供亮度/饱和度、图层不透明度/沉积强度、粗糙度区间、法线强度、height幅度、alpha阈值等本材料确实需要的控制，不预堆无效旋钮。

## 6. 由大到小的视觉迭代

先以256/384全帧缩略图对照冻结参考：材料身份、主要色块、主结构和风化组织必须成立。正常展示不可读时先修对应来源、遮罩、尺度或层参数。干净釉瓷、清玻璃、克制木材和重度锈蚀的目标不同，不能套同一满面旧化。

缩略图成立后看原尺寸局部，检查纹理方向、颗粒/裂纹边缘、拉伸、重复、接缝、位深条带和Alpha边缘。发现明暗污染或不合理起伏时修对应数据来源；提高采样不能补救布局、UV或材料身份失败。执行者必须实际读新图；无看图能力时交接图像与未决判断，不宣称已完成视觉迭代。

临近通过时用有效公开参数做小幅候选，固定镜头和灯光，保存前后对照。旧静态图层在支持范围内可一次study覆盖必要局部/白底与原色候选；程序化2.0另用明确manifest的新候选，不把信号探索塞进旧study。先读基线/差异、参数覆盖和进度，再实际看图选定。赤陶v007(.55/.85)相较v006降幅过大偏灰粉，最终v008(.65/.93)获基本验收；这些数字只说明本例的幅度选择。

## 7. 验证、交付与复盘

执行约定的正常展示、必要换光/关键视角和原尺寸局部；已约定正常两灯/多角度的任务保持约定。其他任务按交付用途、目标变化及风险裁剪，仅存在对应结构或制作目标时覆盖接缝、口沿/内腔、背面。诊断按当前问题区分仅基色、常色仅法线、常色平面仅粗糙度或关闭沉积；关颜色沉积不等于移除Normal/Roughness结构。小幅调参复用未变基线，不机械重跑全套；诊断补光与正常展示分别留证。

从最终信号按通道烘焙；金属BaseColor不能通用使用Diffuse Color，Normal走真正Tangent/+Y烘焙。检查实际分辨率、位深、padding、数值/颜色编码及磁盘重载；IOR超过0..1必须明确编码与解码，Height保留符号、零位和距离。程序化具体路径见[程序化PBR](procedural-pbr.md)。

从正式目录重载外部磁盘图，仅用这些图与声明参数重建材质，独立保存/重开，再与可编辑源在相同条件及必要换光下实际看图比较。若交付Packed，另在无外图目录验证；若交付Editable，核对可编辑源、修改器和实例。CLI退出码、ok、异步终态、文件SHA、图像解码和实际观感各自留证。相对路径必须在最终目录验证；Blender重建不证明Unreal/Unity已验。

交付至少含参考/通道manifest、可编辑节点/源工程、适用图层与依赖、实际预览、来源/用途声明、参数和复现入口；按任务裁剪Packed/交换/性能测试。验收及商用规则见[验收](acceptance-and-promotion.md)，本地技术边界见[工具路由](tool-routing.md)。当前任务记录进度与证据，稳定可复用知识按宿主实际能力维护；缺记忆工具不阻断制作。
