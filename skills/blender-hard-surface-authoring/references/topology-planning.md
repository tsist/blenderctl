# 低密度源笼：先解释全件，再比较候选

## 首要目标与真实面形

合理布线、清楚的支撑职责和可编辑性优先于压低单一残差或总面数。不得让优化器把窄长、扭曲或凹折的控制面当作误差下降的代价；各层证据独立判定。

非共面四边面不能只用面型计数、二维投影凸性或单一对角三角化证明有效。对同一真实坐标按两条对角分别分解，记录三角退化、定向一致性、折叠/凹折风险及最差面；门限来自冻结合同。任一对角分解暴露的问题都不能靠选择另一条对角隐藏。双对角检查也不是整件自交、连续曲面或原生高光合格证明。

## 全件规划

为孔缘、平面场、外缘支撑、圆角、侧壁、底面列出补片及邻接端口。每个端口应能说明有序顶点、方向、锚点、边数、闭合性与相邻面侧。共享坐标不是共享索引，同名标签不是已焊接。

每个候选提交：

- 全件区域图与各区域面数，顶面、底面、孔壁、外缘及侧壁分别计数
- 每条 loop/strip 的形体、锐度、连接或编辑职责；没有当前职责的预铺线不默认保留
- 极点价数、位置、离特征/曲率区距离，以及对插线和滑动的影响
- 源四边面比例、逐处三角例外、零大于四边面的检查；面型合规不代替形状有效和可编辑
- 各边 crease/支撑策略与有限对照，实际完整孔缘环必须核验，不能从一条边类推整环

只比较足以解决当前风险的候选。少一圈孔平面控制环的变体需要与保留该环的变体在相同设计、L2、采样和观察下比较；保留必要面优于强追最低总面数。外缘圆角支撑与孔口支撑职责不同，不随另一处消融一起删除。

## 固定特征框与轴对齐布局

新单孔低笼优先显式 `fixed-frame-axis-aligned/1.1` 布局；`1.0` 仅在当前实现仍支持且任务明确需要旧版兼容时保留，不能静默迁移；字段见[工作单元](work-units.md)。先从当前明确允许的独立孔径/孔位编辑包络选择并冻结特征框与角部保护距离，不以单个基线孔的位置临时推导宏网格。未指定布局的旧路径仅保留兼容，不能据此宣称具备新布局的直线条带与局部编辑保证。

框外宏网格不随孔编辑移动。外轮廓直边上的内部槽位与宏网格轴直接对齐，保留角对角线与切线锚点槽位；不靠加密拉直宽阔平面场。孔缘及必要支撑的变化限于固定框内。大范围直线结构优先，角部局部扇形转接仍属预期，必须展示其实际面角与最差局部，不能用总面数或直线比例掩盖。

有效域须由间隙、局部四边形凸性和局部面角等 guard 共同限定，不是“孔在框内即可任意移动”。以同一冻结框检查基线及各项独立编辑，尤其检查框角附近的扇形转接。超域时拒绝本次输入并重新规划；不能静默移动外框/外部网格、放宽门限或增密使其通过。

新布局保留 v2 语义图和连接职责，但会改变极点等技术坐标。名义外轮廓和尺寸未变不代表旧拓扑图仍证明新布局；比较实际新旧坐标、区域密度及局部扇形，进入新候选 G1 审阅。宿主提案仅说明布局意图，实际源笼证据按[源笼检查](source-inspection.md)取得。

## loop 与 strip 不能靠名字成立

- 规则 edge-loop：真实边序列及局部顶点星形支持约定的连续穿行/滑动
- 边界环：实际边界闭合，但不自动具有规则 loop 的编辑性质
- 过极点 edge-cycle：可以闭合，仍须标出穿越极点的位置和编辑限制
- strip：以真实四边面相邻对边穿行为依据，记录端点端口、插线方向、邻极点和可滑动区间

仅有闭合 edge-chain、标签、线框图片或图论连通不足以证明规则循环。交付实际边/面 ID 对应关系，无法对应就保持未验证。

## 有界插线与后续滑动

本段的滑动约束只在该能力另行实现并验证后适用；当前不能直接宣称独立滑动受支持或已验证。

先做 dry-run：局部新增面、整件新增面、受影响端口、旧新语义映射、非目标不变量与候选输出。任何外端口增点都必须传播到所有邻接圆角、侧壁、底面及必要对称/对应部分；不得只更新可见顶面。滑动不能穿过声明之外的极点或有效域边界。

所有受影响补片准备好后统一校验并提交。部分连接失败应保留旧版本和失败回执，不把半个闭合体当候选成功。语义 ID 不等于顶点索引；拓扑变化输出延续/拆分/合并/失效，歧义必须停，不能最近点猜测。

## 从图到实际几何

图验证之后检查实际 L0 的朝向、退化、翻折、重复面/边、非流形、边界及自交。L0 为拟合 SubD 可合理超出名义轮廓；“超出”不自动失败，但翻折或失去设计含义不能用拟合解释。实际闭合板可以有孔壁，仍应没有开放边界。

规划结果进入 G1 用户结构审阅。若现有插件不能生成/检查所需补片，指出最小能力缺口，不改用密网、固定汇流配方或临时整模脚本掩盖。

## 不为固定面数转移风险

低面数是优先项，不是绝对锁定值。固定外环采样必须与整件圆角段长、侧壁保护带宽度、孔周局部角度和编辑间隙一起检查。只改窄带宽度可能修好侧壁而留下普通圆角长面失败。先保持门限和准确区域角色；必要时比较一条有明确职责、完整传播的新增循环，并列出新增面数、极点/条带影响和编辑器后续能力缺口。不能以更少面换取未经审阅的拥挤平面条带。

## 新增循环也须保护直线

边长不等时，在每条边取同一比例会产生斜向连接。显式 `axis_plane_v1` 在固定原始条带的公共区间选一个轴向截面，再求各被切边的落点，使新增东/南循环分别保持同一X/Y坐标，同时保留全部旧顶点。区间、端口锚点和策略必须与当前参数身份绑定，不能最近点猜测。

当前至多支持两次插线，即可在初次结构补线后再继续一次；不等于无限次数。继续操作必须保留历史前缀，重复位置、拥挤位置及越界要拒绝。交叉后旧循环增点与新循环创建分别记录，实际端口和区域账一起验收。插入后的平面不保证整条周围边界都为规则4价loop，须按真实路径与极点检查。
