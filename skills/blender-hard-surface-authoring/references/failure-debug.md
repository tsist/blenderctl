# 从失败证据找到最小原因

先问数据与图是否来自同一候选，而不是先猜某个拓扑技巧。

## 排查顺序

1. **身份/观察**：文件 SHA、对象/变换、实现、求值层、修改器、法线设置、相机/光照/显示条件是否一致？不同版本的数值与图片不能互相证明
2. **源笼**：实际连接、共享索引、翻折/退化、环职责、极点和局部密度。图合法不保证嵌入几何合法
3. **求值几何**：合同 L2 的轮廓、圆角、孔壁各层、平面、厚度；必要时使用 L1/L3 判断稳定性。升细分只做诊断，不代替修正确原因
4. **真实法线**：几何法线、Blender 实际 CORNER 法线、sharp/smooth/crease 属性及域对应。哈希只能绑定身份，不能还原法线向量；父面标签不等于完整细分影响权重
5. **表面观察**：无叠线形体和多个固定方向高光，保留最差局部。光学代理不等于实际渲染；自然曲率跃迁不凭亮带弯折就判为缺陷

## 常见分叉

- L2 读数超出当前硬合同但 beauty 图好看：回 G3。不能选较漂亮的 L3，改公差或用法线覆盖宣布通过。若当前项目已明确将0.10 mm改为参考，则保留历史fail与读数，不自动强拟合；仍检查结构、形体与高光，不能将参考阈值重新升级为硬门槛
- 控制网格面型全是四边面但条带难编辑：回 G1/G2，解释极点/端口或插线代价，不以面型统计结束
- 改孔位导致外轮廓无关漂移：核对设计/拓扑参数耦合、语义映射和非目标不变量，不先放宽不变量
- 宽阔平面出现斜条带：先检查宏网格与外轮廓直边内部槽位是否同轴、固定框是否被孔编辑重算；不要靠增密解决。角部局部扇形另查面角、凸性和间隙，不能把必要转接与整片斜带混为一谈
- 插线后旧点未动但细分形状变化：先核对实际修改器与前后完整曲面，检查交叉点、极点及支撑邻域。不要用顶点保留报告替代求值差异，也不因无符号距离增大就判外观退步
- 插线后只有顶面闭合：传播未完成，整事务失败；不让底面/侧壁旧端口残留
- 数值通过但固定高光存在凹谷：保留视觉失败，隔离支撑/控制位置/连接/法线及观察因素；未经对照不宣称唯一成因
- 重开或留出失败：当前范围未合格。留出用于调参后转为回归，换独立留出重新评估

## 一轮只改变一个主要因果因素

记录问题、最小假设、变化、固定条件、预期观察、实际结果与下一步。必须联动多项时说明不能独立归因之处。支撑消融使用相同设计、求值、采样和观察；去掉后满足合同且编辑性不损坏，才有删除依据。

失败结果保留参数、最差视图、最小对象/区域和可重现输入。新设计需求与实现缺陷分开：前者重新冻结，后者在当前设计内修插件、跑回归，不偷偷改设计使测试通过。

若原生失败与已有 HOST 原始报告一致，先修汇总或执行前门槛漏检，不能归因于浮点误差。检查整个实体及每个预定状态的原始结果，定位具体面角色与尺寸关系；修一个区域后重新 AND 验证所有区域，防止把失败转移到邻接圆角或窄平面条带。

## 技术渲染成功但图像大部偏暗

这是观察充分性问题，暂记 visibility inconclusive，而非 surface pass 或 geometry fail。先核对实际相机、灯架发光方向、表面反射方向、遮挡、材料和曝光；保留原图，不用后期提亮替代合格原生观察。斜视下朝相机的条带可错过广阔平面的反射方向，仅照亮角部。HOST镜面射线分析可定位这一原因，但不是带粗糙度、遮挡与逐像素积分的完整渲染模型。先做有依据的观察方案修订，再通过实际原生图验证覆盖；不能先改几何、平滑法线或宣称新灯架已成功。dev20案例支持此有限教训，dev21 reflected-anchor仍未原生验证。

## 外部求解未产出候选与覆盖缺失

外部 LP 报告 infeasible 时先核对其源身份、seed、assignment 与 inner-box 约束，结论仅限该次固定组合；不推论整个设计或所有布局全局不可行。没有实际候选坐标时，后续 geometry 为 `not_run`，而非 `fail`。拓扑可独立通过，但不能替未运行几何背书。

曲率比较缺失原 coverage bins、排除项或相同采样身份时，保持比较未验证；不得用新分箱、聚合最大值或其他样本补称可比。完整证据要求见[研究证据关口](research-evidence.md)。不得自动启动新 LP、另造模型或放宽门限消除阻塞；设计变化回 G0。
