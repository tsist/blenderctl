# 编辑与实际细分对照

用于已经接受的受管源笼，需要检查一次明确编辑对 SubD 形状的影响。调用方如果只批准 L0 编辑，不自行加入求值、渲染或拟合；当前可用版本与执行范围从实际接口及本次任务取得。

## 准备完整单元

一个单元绑定源文件字节、源对象、设计修订、参考依据、插件及 Blender 身份，复用受管编辑的保护、保存和独立重开。顺序是母版只读诊断、编辑与重开、新副本只读诊断、HOST 曲面对照。按真实实现设整批与子阶段预算，不把若干独立限额误写成同一总限额。

前后使用完整且一致的实际修改器配置与同一层级集合。L0 是控制笼，不能代替求值层。新副本的对象和几何绑定来自实际重开证据，不能沿用过时的输入快照。dev18的 `edit-review` 1.0 有一次 南侧 `insert_sparse_strip` 原生整链记录；dev19的1.1新增限定单孔板孔径、孔位两个独立整链原生通过。读取当前版本Schema选择操作，不把这些覆盖扩成其他参数域整链、厚度/圆角整链或任意连续组合。

从当前候选的 `hardsurface edit-review plan/run/resume --request` 入口使用同一请求，并以 `describe --section edit-review` 取得完整 Schema；不凭旧示例猜字段。首次单元最多六个顺序原生进程，恢复不重复已有成功阶段。

先读取 plan 结果：确认输入支持域、预计阶段和原生进程上限、输出位置、资源与未测项。运行后每个成功阶段持久保存绑定回执。恢复复核输入、实现及已接受产物；已有阶段不重复提交。状态不明或证据冲突时停在准确的阶段，不改 ID 重跑，也不把目录中存在候选文件写成整个单元成功。

## 读取比较结果

拓扑变化后，顶点与面索引通常不同。比较同层的双向采样点到对方完整三角曲面的最短距离，不做跨网格索引相减。前后语义父面槽位只在各自网格内部解释；区域汇总应注明“本侧区域样本到对方整件曲面”，不能说已经证明逐面语义对应。

保留全件采样数、最大差异的位置、两方向数值、各真实区域、每个极点邻域、边界及完整循环覆盖；列明未覆盖域。所有三角形中心或顶点都采过，仍然只是有限采样；不等于连续 Hausdorff 距离、解析极限面或轮廓像素保证。遗漏、退化、未绑定或资源不足必须显式拒绝或未测，不能只输出一个通过摘要。

较大无符号距离只说明不同，不直接表示变差。查看真实线框/剖面与名义形状的方向关系，再按当前结构、支撑形状、编辑性和尺寸优先级判断。若尺寸阈值只是参考，报告超参考的样本数，不据此自动拒绝、拟合或加线；若项目另有硬验收约定，则仍遵从该合同。

## 分开结论

- 执行：是否完整完成编辑、独立重开、两侧诊断、受保护文件与实际源网格检查
- 采样：用何种层级、配置、坐标、采样及区域覆盖得到哪些数值
- 形体审查：真实整体与最大局部是否已查看，具体可见变化及用户接受范围
- 未测：连续曲面、校准轮廓、实际法线/高光及用途资格中没有证据的项目

原控制点不动、全四边面、执行成功或低数值都不单独证明保形。人工和用户审阅结论不由工作单元自动写成通过。
