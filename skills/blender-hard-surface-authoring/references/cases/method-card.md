# 方法卡：记录可复用判断，而非按钮流程

仅在真实案例新增可靠结论或反例时填写，留在获准的项目交付或维护位置。不要将私有项目身份、个人资料、参考图或历史许可复制进公开技能包。

- **问题与适用条件**：什么形体、特征关系、参数域和用途会遇到它？
- **当前结论**：外部启发、实战候选、单案例支持或限定族验证？
- **最小原因假设**：为何应有效，与哪些替代解释仍未区分？
- **实施与固定条件**：确切版本、主要变化、保持不变的设计/求值/观察
- **实际证据**：图检查、宿主、原生、视觉、用户、重开/留出分别列状态和可查引用
- **编辑影响**：E1–E4、端口、ID 映射、非目标与增面成本
- **失败边界与替代**：最小失败输入、拒绝或退回哪一关，什么仍未测
- **新增回归与迁移**：加入哪些案例；若调过留出，明确已转为回归
- **下一次使用**：足以复用的条件与必须重新验证的变化

不填写虚构成功案例。方法卡数量和测试数量不构成成熟证据，范围接受由真实关口结果决定。
