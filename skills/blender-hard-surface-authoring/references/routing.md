# 选路：用途、构造与当前支持域

## 用途先于拓扑配方

从当前任务读取交付用途、最近观察距离/画幅、轮廓要求、后续编辑、运行预算和目标文件。只澄清会改变路线且无法从来源核实的缺项。

- **影视/产品**：分别交付可编辑 L0、约定求值高模及观察证据。单张远景好看不能为近景或所有光照背书
- **游戏**：保留独立母版，在明确三角/贴图预算与交换目标后再做低模派生。不得因用户提到游戏直接三角化母版，或从影视合格推断实时合格
- **两者都要**：共享冻结设计与母版身份，分别列出尚缺的交付证据；不让尚未实现的游戏链阻止已获准的母版阶段工作

## 当前批次边界

开发对象是**一个圆通孔、闭合、带厚度的平板母版**。外轮廓、孔缘、平面场、外缘支撑/圆角、侧壁和底面必须共同成立。图上的顶面计数不是整件计数。采样点数、孔口支撑有无等只是经验证的有限候选，不是所有形体的固定配方。

先从插件当前 Schema 和实际实现取得参数域；若源码、文档和回执冲突，停止依赖该能力的执行并核实版本，不能挑宽松说明继续。既有 `sparse_annulus` 显式网格路线与新稀疏 SubD 补片路线不是同一能力。

支持域外必须给出具体缺口和最近可行下一步：只读识别、参考补全、插件适配或独立扩展案例。不能偷偷改孔位、厚度、公差或拓扑政策使请求进入域内。

## 参数改动与新增结构的分流

已有母版的孔径、孔位、厚度、外缘圆角分别有限定案例独立编辑证据；dev18已有一次插线整链，dev19新增限定单孔板孔径与孔位两个独立整链原生通过。参数编辑核对当前冻结实现与支持域；其他参数域、厚度/外缘圆角整链及新的组合不能继承上述两例资格。连续组合需另设有界验证，不能从独立编辑推导。

第二孔、槽孔、薄壁或更高阶实用物件需要新的任务范围与参考，不能冒充当前单孔板的现成能力。用户可明确选择暂停既有优化并推进新案例；保留旧案例未完成状态、技术边界和已有证据，不将转向解释为完成或资格通过。仅请求进度/规划时可说明路线，无需启动建模。

## 后续族的选取与依赖

下面是技术依赖提示，不是必须逐级结业的课程。按用户当前用途、案例知识与最小可复用能力选择下一件实用物件；不要求把所有旧案例优化项完成后才能提出新案例。新案例不能继承旧案例未获得的资格，仍须重新确认效果、规格、细节参考与执行范围。

1. 第二圆孔、非圆槽与邻近特征关系分别建立局部支持域和连接证据
2. 薄壁壳与简单盖体将厚度、开口、支撑和配合关系分关验证
3. 回转截面、圆方过渡、单曲率开孔罩各有自己的点序/端盖/母面证据
4. 小总成仅组合已合格部件，仍需接口、间隙和变更传播验收
5. 未见组合只在已声明域内做冻结版迁移检验，不借留出名义加入新几何原理

这些是候选扩展方向，不是当前支持清单，也不替未来资产冻结设计。若用户暂停单孔板优化，保留其开放的观察与用途资格项，不把继续优化它设为与新案例无关工作的自动前置条件。

## 既有网格

先辨别受管参数化母版、可识别但未受管网格、无法可靠识别三种情况。只读读取真实对象/修改器/区域与依赖即可；没有可靠语义映射时，不用最近点补造身份。修复必须有对应已合格构造族、明确受影响范围和回归方法。任意网格修复、复杂扭转分支、制造/CAD/Class A 或具体引擎认证均不由首件孔板推导。
