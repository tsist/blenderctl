# 游戏派生：保持母版，逐段建立证据

此处是后续工作路线，**不是首批已实现能力**。先完成相关单孔/特征平板几何资格；游戏链路不继承影视高模资格。调用前通过当前工具 Schema 核实所需能力。

## G-A：独立低模、UV 与固定三角连接

输入：合格母版身份、目标轮廓/观察、三角面预算、贴图尺寸与密度/padding 约定、目标交换格式。缺关键预算时先澄清，不捏造统一 texel density 或压缩标准。

输出：独立低模副本、与母版的轮廓对应、UV 接缝与密度检查、明确固定的三角连接。可编辑母版仍四边优先；受控三角化发生在派生副本，三角策略与导出后实际连接需一致。简单减面后给一个面数不能算完成。

## G-B：烘焙与目标读取器重开

锁定高低模配对、cage、法线/切线约定、UV 和三角连接，再烘焙。实际查看孔槽、硬边、镜像、接缝和遮挡处，核查投射失误；验证交换文件在目标读取器的法线、材质与贴图依赖。

任一连接、UV、法线或切线改变，使受影响旧烘焙证据失效。没有对应工具/设置证据时不能声称跨 DCC crease 一致、引擎认证或游戏就绪。

## G-C：LOD

基础烘焙/交换链稳定后，一次加入一个需要的 LOD 级别。每级实际看应用贴图后的轮廓、法线和切换损失，并检查目标预算。不要凭固定减面比例或最低面数替代视觉验收。

引擎无关链通过之后，具体引擎材质、压缩、碰撞、导入设置及性能另行验收。只交付用户要求且已完成的层，不为填满路线表制造无关派生物。
