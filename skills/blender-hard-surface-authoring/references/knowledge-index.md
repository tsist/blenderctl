# 知识入口与证据晋升

以下按六类机制组织当前适用知识，不构成已实现能力清单。只读取当前问题相关的来源，研究图片不随技能打包。

| 机制类别 | 本批可用的判断及入口 | 仍未获得的资格 |
|---|---|---|
| 孔与补片 | 孔闭环、平面转接、端口边数、极点与源/求值配对；见[低笼规划](topology-planning.md)、[源笼检查](source-inspection.md) | 支撑展开不等于减密；平面证据不证明双曲率 |
| 锐度与支撑 | 锐度与几何半径分开，检查支撑/crease/Bevel 范围与交汇；见[参考合同](reference-contract.md)、[低笼规划](topology-planning.md) | 没有同目标对照不宣称某一锐度路线普适最佳 |
| 厚度与内壁 | 孔入口、孔壁、出口与厚度同版检查；见[源笼检查](source-inspection.md)、[资格](qualification.md) | 闭合单孔不证明双壳、薄壁盒盖或配合间隙 |
| 端口与截面 | 端口方向、点序、截面身份与闭合关系；见[低笼规划](topology-planning.md)、[选路](routing.md) | 本批不验证回转、封端或跨截面过渡样件 |
| 法线与显示 | 几何、实际法线与显示设置隔离，原生笼/求值/高光配对；见[诊断](failure-debug.md) | 法线美观不证明曲率、厚度或自交合格 |
| 设计与执行 | 设计/技术/求值分离、受管编辑和全作业资源；见[工作单元](work-units.md)、[资格](qualification.md) | 稀疏不自动更优，中间大多边形不能进入母版；游戏链另验 |

本包不附私有研究附件，也不声称提供相关原文。具体软件接口仍以当前 Schema/实现为准，不从研究文献推导可调用命令。

方法按“外部启发 → 实战候选 → 当前案例支持 → 限定资产族验证”晋升。每次绑定适用条件、实际证据、实现/运行版本和反例，使用[方法卡](cases/method-card.md)。只有代码或宿主测试时保持相应证据状态；原生技术、实际视觉、用户认可和迁移互不替代。

没有可复用的新证据时无需增加方法卡。失败卡可以比成功卡更有价值，但不把单个反例扩成无条件禁令。用途派生另读[游戏链路](game-derivation.md)，不把研究覆盖面变成首批已实现范围。
