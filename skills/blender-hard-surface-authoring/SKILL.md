# Blender 低密度硬表面制作

以完整、可编辑的低密度母版推动能力开发。插件承载领域逻辑，CLI 调度完整工作单元；此技能负责选路、输入、审阅关口和证据解释，不实现第二套建模引擎。

这是与 dev21 候选配套的**公开开发版指导**，不是稳定发行或安装回执。当前首批仅针对闭合单圆通孔板：限定单孔板完整体母版及限定编辑已有真实原生证据；正式表面观察、用途资格与冻结版留出尚未完成。源码、宿主测试、原生技术、视觉检查和用户阶段认可分别记账；不把已完成技术证据降为未测，也不把限定案例通过扩成通用造型能力。确切实现及当次证据从交付清单、当前 Schema 和完成回执取得，见[工作单元与能力状态](references/work-units.md)及[发布来源](references/provenance.md)。

## 先选路线，再取得可信输入

- 新构造或参数修改：先读[选路](references/routing.md)，优先已支持参数化族；不把旧的固定采样构造器当成新低密路线
- 建模起点：读[参考合同](references/reference-contract.md)，核对实际效果、规格与必要细节，取得当前设计的冻结版本；只有文字尺寸、历史批准标记或拓扑示意图不构成完整起点
- 结构取舍：读[低笼规划](references/topology-planning.md)，为每个环带、极点与端口解释形体或编辑职责。新单孔低笼优先显式冻结轴对齐布局，使大范围条带保持直线、孔编辑局限在固定特征框内；无布局字段的旧行为只用于兼容。可编辑源网格四边优先，三角例外必须逐处声明，禁止大于四边面；游戏三角化只作用于独立派生副本
- 既有网格：先只读识别与报告。对应参数化族未合格前不承诺自动修复；歧义、不受管漂移或域外结构停在准确缺口

## 关口按依赖推进

每个关口记录 `pass / fail / not_run / not_applicable`；不适用必须有合同理由。技术通过、视觉通过和用户接受是不同结论。必需项失败或未测不被总测试数抵消。

| 关口 | 必需结果与停止点 |
|---|---|
| G0 参考与身份 | 实际参考一致、尺寸/观察/编辑合同冻结，源和实现可追溯；冲突未决不生产建模 |
| G1 整件 L0 | 输出实际未求值网格的正背面、孔内壁/出入口、全部接缝及区域账；检查真实边流、极点、面型、连接与密度。**用户审阅通过后，才推进依赖该结构的 SubD 拟合和高光优化** |
| G2 编辑性 | 从同一已接受基线分别做 E1 孔径、E2 孔位、E3 约定基准下厚度、E4 外缘圆角编辑；另验已实现的有界插线及全件端口传播；独立滑动按能力状态单列。新增孔槽不是本批自动能力 |
| G3 求值形体 | 当前既有验证案例以合同 L2 为验收层，L1/L3 只作诊断与稳定性；名义尺寸、技术弦高、有限采样距离与像素误差分开，不能择优替换或改阈值 |
| G4 真实表面 | 同一模型身份的实际法线、无叠线形体、多方向高光及最差局部齐全；漂亮图和法线覆盖不能替代几何合格 |
| G5 交付与迁移 | 独立保存重开、依赖、编辑回归、冻结版留出及用户限定范围接受；未完成不得声称本族或用途成熟 |

G1 用[实际源笼检查](references/source-inspection.md)；G2–G5 用[资格与交付](references/qualification.md)。批准结构后若修改改变连接、环职责或产生非预期主要形变，重新提交受影响的 G1 审阅，不沿用旧图证明新结构；同拓扑的已批准 E1–E4 批次按资格参考组织 G2。

## 执行与定位失败

准备执行时按名称读取现场 `blender-work-methodology` 与 `blender-cli`，按[工作单元](references/work-units.md)核对当前插件、Schema、支持域和授权。将构造/检查/保存组成可验证单元，源文件与候选分离。少调用不能省略实际观察；能力缺口不以临时整模脚本或静默换构造器掩盖。

插线后需要审查细分形状时，读[编辑与细分对照](references/edit-subdivision-review.md)，按操作区分已有完整工作单元与开发入口：dev18 有一次 南侧插线整链原生证据；dev19 新增 限定单孔板孔径、孔位两个独立整链原生通过，不扩为任意连续组合或厚度/圆角整链。原控制点保留只证明编辑不变量，不能据此宣称细分保形。

身份不符、求值不达标或反光异常时读[分层诊断](references/failure-debug.md)，保留失败视图，一次检验一个主要原因。先修发生问题的层级，不用增加面数、细分等级或材质细节遮盖失败。

## 交付分路，经验按证据增长

用户可以暂停旧案例优化并选择更高阶实用物件。保留开放问题与能力边界，按新对象重新确认参考和执行范围；不要把旧案例未完成误写成完成，也不要强制先完成其全部优化才允许新案例规划。

影视/产品母版和游戏链路独立资格；游戏需求读取[游戏派生](references/game-derivation.md)，按低模/UV/固定三角连接 → 烘焙/重开 → LOD 逐批加入。首批不包含完整游戏生产链。

材料进入 `blender-material-authoring`，Catalog/入库进入 `blender-asset-manager`。只在对应任务需要时加载；它们不替本技能判定几何合格。

有可复用发现时用[知识入口](references/knowledge-index.md)和[方法卡](references/cases/method-card.md)记录条件、因果、失败边界和真实证据。外部启发、单案例成立和限定族验证分开；不携带私人工程、研究图片或历史授权，不从源码包或备份推导质量资格。
