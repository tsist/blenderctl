# Rigging development baseline

The separately published [Blender Rigging Workflow](https://github.com/tsist/blender-rigging-workflow) contains the existing base add-on, selected later SDK components and the single blender-rigging skill. Basic feature areas are present; detailed quality has not been accepted and later components do not yet form one unified UI.

Install its base add-on ZIP through Blender Preferences, or use its documented explicit source setup. Character assets, private profiles and third-party add-ons are not included. Bones/controls, binding weights, expression Shape Keys and hair physics are in scope; fixed large-angle cycles and intermediate frames are inspection tools, not animation production.

The current public blenderctl runtime remains 0.63.0. The project workstation uses newer CLI code, but unrelated unreleased experiments are not merged by this companion publication. Verify the exact capabilities/schema required by each developer request before executing it; this update does not certify that every newer SDK request runs on the older public runtime.

Existing managed extension.run can execute explicitly authorized scripts under its actual contract. There is no new universal public rigging command, and no source-bound workstation receipt may be reused after export. See the independent repository for setup and concrete component limits.

Future integration candidates include Auto-Rig Pro, auto-rigpro-ai, Rigify, wiggle-2-rtx-version, an Aon panel addition script and voxel skinning. They are not bundled. Detailed requirements and licensing will be established in the next task's formal interview.
